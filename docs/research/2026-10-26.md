## 3. お金の払い方（事実）

### 3-1. LINE の中で払う仕組みは、今は使えない

- LINE Pay は国内で 2025年4月30日までに順次終了し、PayPay に一本化された（2024-06-13 の LINEヤフーの発表を報じた記事）。
- LINE AI の有料プランは LINEヤフー自身のサービスなので LINE アプリの設定から申し込めるが、焚き火のような一般の公式アカウントが同じ仕組みを使えるという資料は見つからなかった。焚き火は外の決済（Stripe など）を使う前提になる（CLAUDE.md の方針どおり。オーナーの仕事）。

### 3-2. Stripe の支払いリンクで「誰が払ったか」を受け取る方法

- Stripe の Payment Links には `client_reference_id` という URL パラメータがあり、英数字・ハイフン・アンダースコアで200文字までの好きな値を付けられる。支払いが終わると `checkout.session.completed` の Webhook でその値が届く。決まりに合わない値は黙って捨てられる。
- Stripe は、リンクが思わぬ所に出回りうるので、この値に秘密や機微な情報を入れないよう注意している。
- LINE のユーザーID は `U[0-9a-f]{32}` の形（LINE Developers）。英数字だけなので `client_reference_id` に入る長さ・文字に収まる（文字数は形から計算。Stripe 側で試してはいない）。同じ人でもプロバイダーごとに違う値になる。
- 焚き火に当てはめると（推測）：月額の仕組みを作るなら「有料のユーザーID」を覚えておく必要がある。会話の内容ではないが、今の焚き火は会話をメモリに持つだけで何も覚えないので、**新しく記録するものが生まれる**。ワーカー1・メモリだけの今の作りでは再起動で消えるので、どこかに保存する話になり、約束2（保存しない）との線引きを安全審査部とオーナーが決める必要がある。
- Stripe の日本の手数料は、公式の料金ページが今日は読めなかったので書かない。

## 会社への示唆（3つ以内）

1. **CLAUDE.md の相場「月200〜980円」は古くなっている。** 下限 200円の LINE AIアシスタントは 2026-01-07 に提供を終えた（二次情報）。今も提供が確認できる LINE 上の AI は月750円（LINE AI 使い放題、公式）〜980／990円（AIチャットくん、二次情報）。CLAUDE.md は会社からは書き換えないので、「月750〜990円程度（2026-10 時点）」への直しを社長からオーナーに提案する（`docs/owner_todo.md`）。
2. **候補5（1日の回数の上限）を考えるときの目安は「無料は1日3〜5回」。** ただし競合は質問1回を1回と数える道具で、焚き火は1回の吐き出しが何通にも分かれる（推測）。同じ「5回」を発言の数で数えると、吐き出しの途中で止まりかねない。数え方（発言か、燃やすまでの1回か）を先に決め、上限に達しても危ない言葉が当たった発言には安全の案内を返す作りを条件にしたい（推測。決めるのは企画部・安全審査部）。
3. **月額の仕組みを作ると「有料の人のユーザーID」を新しく記録することになる。** LINE の中で払う仕組みは使えず（LINE Pay 終了）、Stripe の支払いリンクで ID を受け取る形が現実的。会話は残さなくても、約束2との線引きと保存場所の判断が要るので、第2段階はオーナーと安全審査部の判断が先。それまでは第1段階（見返りなしの応援）のままでよい。
