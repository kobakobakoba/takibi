# 調査メモ 2026-10-17：ケアラーが言われてつらい言葉・困っていること（PERSONA と候補7・8の材料）

調査部。社長の参考は `じさつ`・`ぎゃくたい` の出典探しだったが、10-13 から10-16 まで4日続けて危ない言葉の一覧を調べており、10-16 にも「当事者がひらがなで書く出典はない」と確かめたばかり。もう一度探しても見つかる見込みは低い（推測）。そこで今日は、まだ一度も調べていない**当事者ニーズ**を取り上げた。具体的には「育児・介護をしている人が言われてつらい言葉」と「困っていること」で、焚き火の `PERSONA`（会社の判断で直してよい範囲）と、候補7（育児／介護のモード分け）・候補8（夜間モード）の判断材料にする。

前提（`main.py` 37〜50行を読んで確認）：今の `PERSONA` が禁じているのは、説教、正論で諭すこと、「親なんだから／家族なんだから」、頼まれていないアドバイス。**「がんばって」系の励ましや、同じ愚痴をくり返す人への言い方については何も書いていない。**

※ 個人の投稿（note・SNS）は使っていない。使ったのは、企業・団体・自治体が集計したアンケートと公的な調査。自由記述の例は要約し、引用は1つの出典につき1回までにした。

## 1. 言われてつらかった言葉（事実）

| 出典 | 対象・規模 | 分かったこと（要約） |
| --- | --- | --- |
| 認知症の人と家族の会「認知症の介護家族が求める家族支援のあり方」報告書（平成23年度老健事業、2012年3月） | 認知症の人を介護している家族 557人 | 自由記述で挙がったつらい言葉・扱い：**「もっと頑張れ」と励まされること**、元気そうに見えるので怠けている・大げさだと思われること、本人の昔の姿と比べる同情、親族からねぎらいがないこと、専門職に相談しても十分に聞いてもらえないこと。救われたのは、同じ立場の人の言葉で自分だけではないと思えたこと、家族から一人で休むよう声をかけられたこと、何でも聞いてくれるケアマネジャーに出会えたこと |
| 同会「介護保険の困りごと」アンケート報告書（2019年5月） | 46都道府県 289件（約7割が介護中・経験者） | ケアマネジャーに、毎日来ないことや同居しないことの理由を問われ、精一杯やっているのに責められたと感じた例 |
| ミキハウス「ママ・パパ禁句調査」（2019年8月） | ベビークラブ会員 3,527人（ほぼ女性） | パートナーの言葉で傷ついた経験がある人は55%（たまに37%＋何度も18%）。言われた言葉を覚えている人は83%。例：睡眠不足を訴えたときに**「またそれか」**と返される、育児の悩みを話しても分かってもらえない、夫が育児を「手伝う側」として話すことへの違和感 |
| 講談社コクリコ×AnyMaMa のアンケート（2024年6月、記事は2024年8月24日） | 109人（産後の母親） | 夫に母親ならもっと努力するよう言われた、夜泣きは母親が見るものと決めつけられた、実母に母乳のことで責められた、など（要約） |

**まとめ（事実）**：介護でも育児でも、もっと頑張れという**励まし**と、同じ訴えを**軽く扱われること**が、つらい言葉として挙がっている。どちらも、焚き火が今禁じている説教や「親なんだから」とは別の種類。

## 2. 困っていること・求めていること（事実）

- **自分を責める気持ち**：認知症の人を介護する家族の80.7%が、優しくできない自分に嫌悪感があると答えている。意欲が出ないことが「よくある・時々ある」人は85.5%（家族の会 2012）。
- **話を聞いてほしい**：介護家族が求める支援でいちばん多かったのは介護者の心のケア（75件）で、中身は話を聞いてくれる場や人（家族の会 2012）。子育て中の親では、本音や悩みを口に出せたら楽になると答えた人が79.3%、「もう無理、限界」と感じたことがある人が49.3%、身近に相談できる人がいない人が23.5%（コミットグロース、2023年、1,007人）。
- **相談先を知らない・自分がケアラーだと思っていない**：山梨県のケアラー実態調査（2025年1〜2月、有効回答1,851人のうちケアラー485人）では、ケアラーがほしい支援のいちばんは相談できる人や場所（57.5%）。精神的な不調があるケアラーは41.0%。支援する側の機関は、支援が進まない理由として、ケアラー本人に自分がケアラーだという意識がないこと（56.6%）と、相談先を知らないこと（47.6%）を挙げた。
- **介護の中身より「気持ち」と「家族のこと」**：在宅介護の経験者575人（エリエール、2024年7月）に聞くと、負担が大きいのは排泄の介助（57.6%）が最多。ただ、介助以外で思ったよりつらかったこととして、家族の中の役割分担や不公平感、自分の時間がないこと、ストレスの発散のしかたが分からないことが挙がった。自由記述には「親が申し訳なさそうにしていることがつらい」もあった。
- **子育ての孤独**：子育て中・経験者998人（PIAZZA、2024年3〜4月）では、孤独を感じた場面のいちばんは「子どもと二人きりでいる」とき（女性59.4%、男性47.5%）。第一子が0歳の時期に孤独を感じた人が57.9%。

## 3. 育児と介護は分けられない人がいる（候補7の材料。事実）

- **ダブルケア**（育児と介護が同時）をしている人は約25万人と推計されている（女性約17万人、男性約8万人。30〜40代が8割）。内閣府男女共同参画局「育児と介護のダブルケアの実態に関する調査」（2016年4月公表、平成24年就業構造基本調査をもとにした推計）。
- 山梨県の調査では、**ケアラーの27.8%が2人以上を同時にケア**している。
- エリエールの調査でも、仕事や家事・育児との両立が負担だという人が34.3%いた。

## 4. 夜の困りごと（候補8の材料）

- 事実：介護家族の42.9%が睡眠時間が減ったと答え、自由記述には夜中の排泄介助やおむつ交換で眠れないという声がある（家族の会 2012）。「介護保険の困りごと」（2019）にも、夜のおむつ交換や痰の吸引で眠れないので夜間の支援がほしいという声がある。同居の主な介護者のうち、介護に「ほとんど終日」かかっている人は19.0%、要介護5では63.1%（生命保険文化センターが国民生活基礎調査 2022年をまとめたもの）。
- 事実：0〜3歳の育児で困ったことの上位に寝かしつけがあり、月齢にかかわらず多い（樋屋製薬・ベネッセ、2025年1〜2月、503人。割合は画像のみで読めなかった）。
- 事実（ただし偏りあり）：東京都の児童虐待防止LINE相談のトライアル（2018年11月、平日9〜21時）では、平日の相談は19時台がいちばん多く、17時以降に集中した。受付が21時までなので、**深夜にどれだけ相談したい人がいるかはこの資料からは分からない**。
- 推測：夜中に起きて介護や授乳をしている人がいることは出典で裏付けられた。ただ、焚き火が深夜に使われているかどうかは会社からは見えない（Render のログも利用者数も見えない）。

## 5. 焚き火に当てはめると（推測）

| 分かったこと | 今の焚き火 | 考えられる手当て（推測。すべて `PERSONA` の範囲。会話の保存は増えない） |
| --- | --- | --- |
| もっと頑張れという励ましがつらい | `PERSONA` は「がんばって」を禁じていない。AI が気をきかせて「無理せず頑張ってね」と返すことはありうる（推測。本番の返事は見えない） | 「がんばって」「もっと〜しよう」と励まさない、という1行を足す |
| 同じ訴えを軽く扱われるのがつらい | 1つの会話の中で同じ愚痴が続いたときの指示がない | 同じ話がくり返されても「また？」と言わず、毎回はじめて聞くつもりで受け止める、という1行を足す |
| 優しくできない自分が嫌になる（80.7%） | イライラを否定しない指示はあるが、自分を責める気持ちには触れていない | 自分を責める言葉が出たら、責めずに疲れのほうを受け止める。ただし「あなたは悪くない」と言い切ると、虐待の話が出たときの SAFETY と食い違うおそれがあるので、文言は安全審査部と決める |
| 自分がケアラーだと思っていない人が多い | `PERSONA` 冒頭は相手を「世話を毎日がんばっている人」としている | 「がんばっている」も励ましに近い。今は相手の説明なので急がないが、上の1行を足す日に合わせて見直してもよい |
| ダブルケアや複数の人のケア | 候補7は「育児」「介護」の2つのボタン | 二択にすると両方している人が迷う。案A：ボタンを出さず、`PERSONA` に「育児と介護の両方、または複数の家族を世話している人もいる」と書くだけ（状態を持たない）。案B：ボタンに「両方」「選ばない」を足す（選んだ結果はメモリの会話にだけ置き、燃やすと消える。新しく覚える情報が1つ増えるので安全審査部の確認が要る） |
| 夜に眠れない介護・育児 | 候補8（0〜5時は短く静かに） | 根拠の半分（夜に起きている人がいる）は出典あり。残りの半分（深夜に焚き火が使われる）は分からない。モデルは今の時刻を知らないので、どの案でも時刻を渡す処理が要る（案ごとの比較は企画部で） |

- 守ること：どの案でも、利用者の発言を分析・保存しない。発言から「この人は介護」などと推定して残すこともしない。医療・制度の判断はしない（夜間のヘルパーを勧めるような助言は、頼まれていないアドバイスにあたる）。

## 会社への示唆（3つ以内）

1. **`PERSONA` に「励まさない」「くり返しを軽く扱わない」を1行ずつ足す価値がある。** 当事者のつらい言葉として、もっと頑張れという励ましと、同じ訴えへの「またそれか」が挙がっているが、今の `PERSONA` はどちらも禁じていない。`PERSONA` の範囲だけで済み、保存も増えず、差分は数行（推測）。自分を責める気持ちへの寄り添い方は、SAFETY と食い違わないよう安全審査部と文言を決める。
2. **候補7（モード分け）は「育児」「介護」の二択にしない。** ダブルケアは約25万人、2人以上をケアしている人は27.8%。まずはボタンも状態も持たずに `PERSONA` に「両方の人もいる」と書く案A が小さくて安全（推測）。
3. **候補8（夜間モード）は、夜に眠れずケアしている人がいることは出典で裏付けられたが、深夜に焚き火が使われるかは分からない。** 時刻を渡す処理が要るので、示唆1より後でよい（推測）。
