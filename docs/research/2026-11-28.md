# 調査メモ 2026-11-28：地域包括支援センターの「別の呼び名」と、`SAFETY_REPLY_MARKERS` の続き (3) に足す語の誤検知の下調べ（`児相`・`精神保健福祉センター`・短い形）

調査部。直近は 11-25（プロンプトキャッシュ）、11-26（説明文の見直しの下準備）、11-27（相談窓口の全体確認）。年末年始の当事者ニーズは 11-08、年末年始の命の危なさは 11-19 に調べ済みなので、今日は重ねない。

今日のテーマは、バックログの候補「`SAFETY_REPLY_MARKERS` の続き (3)」（`子供SOS`・`児相`・`精神保健福祉センター`・**地域包括支援センターの別名**：「出典・誤検知の例を挙げてから1語ずつ」）の下調べ。LINE SDK に依存しない（`main.py` 93〜96行のリストだけの話）ので、企画部が明日以降に選べるかを判断する材料になる。窓口が今も有効かの確認ではない（それは 11-27 に済み、要修正なし）。

## 結論（先に）

1. **地域包括支援センターは、自治体ごとに別の呼び名を使っていることが多い**（公式ページで確かめた例は下の表の11例。11-28 安全審査部の指摘で数を表にそろえた）。今の目印 `地域包括支援センター` は、AI が別の呼び名だけを書いた返事には当たらない。
2. ただし **SAFETY（`main.py` 69行）は AI に「地域包括支援センター」とその名前で案内するよう書いている**。AI が別の呼び名だけを書くのは、利用者が自分の市区町村や呼び名を書いた場合くらいと考えられる（**推測**。本番の返事は会社から見えない）。別の呼び名を足す効き目は小さい。
3. **短い形は誤検知の穴になる**ので足さないほうがよい：`包括支援センター` は旧「子育て世代包括支援センター」に、`地域包括` は「地域包括ケア」に、`児相` は「**育児相談**」「乳幼児相談」に部分一致する（文字列として確かめた。下の 3）。どれも普通の子育ての返事に出うる言葉。
4. 足すなら、高齢者向けとはっきりわかる長い呼び名（`あんしんすこやかセンター` など）を1語ずつ。`精神保健福祉センター` は公的に全国（都道府県・指定都市）に置かれていて、誤検知の例は見つからなかった。

SAFETY の要修正なし（今日は窓口の有効性を見ていない。11-27 の確認のまま）。

## 3. 短い形・(3) のほかの語の誤検知の下調べ

`has_safety_markers()` は部分一致（`main.py` 117行）。足す語が普通の返事に含まれる文字列の一部になると、そのたびに応援リンクが出なくなる（守る側に倒れる誤検知）。

| 足す候補 | 部分一致してしまう普通の言葉 | 確かめ方 |
| --- | --- | --- |
| `包括支援センター` | 旧「子育て世代包括支援センター」。船橋市では令和8年4月に「こども家庭センター」へまとめた（更新 2026-04-01）。〔出典 Q〕国の法改正で見直しが原則 2024-04-01 施行。〔出典 R〕名前はなくなりつつあるが、AI が古い名前で子育ての相談先として出す可能性はある（**推測**） | 文字列として含む（確認） |
| `地域包括` | 「地域包括ケア」「地域包括ケアシステム」（介護の一般的な説明に出る言葉） | 文字列として含む（確認） |
| `児相` | 「**育児相談**」「乳幼児相談」（「育・児・相・談」の並びに「児相」が入る）。普通の子育ての返事に出やすい | 文字列として含む（確認）。**足さないことを強くすすめる** |
| `精神保健福祉センター` | 見つからなかった。都道府県・指定都市に置かれ、心の健康の相談を電話・来所で無料で受ける公的な機関（厚労省「こころもメンテしよう」）。〔出典 S〕 | ページに更新日の記載なし |
| `子供SOS` | 見つからなかった。ただし AI が「子どもSOS」とかなで書くと、`fold_kana()` では「供」と「ども」がそろわず当たらない（照合の仕組みからの確認） | 11-09 に まもろうよ こころ の電話ページに載ることは確認済み（`docs/research/2026-11-09.md`）。子ども向けの窓口 |
| 長い別の呼び名（表の語） | 見つからなかった。`ケア24` は短いが、普通の愚痴の返事に「ケア24」が出る場面は思いつかなかった（**推測**） | 誤検知の例を探したのは調査部の頭の中と表のページだけ |

## 会社への示唆（企画部向け、3つ以内）

1. **`SAFETY_REPLY_MARKERS` (3) は、選ぶなら「`精神保健福祉センター` 1語だけ」が一番小さく安全**（LINE SDK に依存しない、リストに1語＋テスト）。公的な機関で、誤検知の例は見つからなかった。ただし効き目は「AI がその名前を出したときの守り」で、出す頻度は見えない。選ぶ前に安全審査部の事前意見を聞く（候補の決まりどおり1語ずつ）。
2. **短い形（`児相`・`包括支援センター`・`地域包括`）と `地域ケアプラザ` は足さない**ことを候補欄に記録するのをすすめる。特に `児相` は「育児相談」に当たり、普通の子育ての返事で応援リンクが出なくなる。誤検知の見張り（`ORDINARY_COMPLAINTS` とは別に、返事側の当たらない例）を足すなら「育児相談に行ってみては」が使える。
3. **地域包括支援センターの別の呼び名は、急いで足さない**。SAFETY 69行が AI に正式名で案内させているので、足しても効く場面は小さい（推測）。足す日が来たら、表の長い呼び名を出典つきで1語ずつ。広報部へ：地域ごとに呼び名が違うことは事実だが、特定の自治体の窓口名を投稿に載せない（焚き火は全国向けで、地域の窓口を案内する作りではない）。
