# 調査メモ 2026-10-13：危ない言葉の一覧（`SAFETY_USER_WORDS`）の見直し ― 材料集め

調査部。テーマは社長の指定（バックログ新候補「危ない言葉の一覧の見直し」）。
(1) 公的機関・支援団体の資料にある「遠回しな言い方」「サイン」を、育児と介護の両方で集める。
(2) 候補ごとに誤検知（普通の愚痴でも当たる）の多さを評価し、3つに分ける。
(3) 余力で、line-bot-sdk v3 の振り分けの順番を github.com 以外で読めるか試す。

前提（`main.py` を読んで確認）：一覧は**部分一致**で、利用者の今回の発言に一覧の言葉が「含まれて」いれば当たる。当たると (a) 燃やした後の応援リンクを出さない、(b) AI が答えられなかったときのおわびに 110番・119番の一文を添える。AI の通常の返事や SAFETY ブロックの指示には効かない。

※ 引用は1つの出典につき1回までにしたので、資料が挙げている言い方の多くは「型」として要約して書いている（下の表の言い方は、資料の文そのままではなく、照合に使う短い形）。個人の投稿は使っていない。

## 1. 公的機関・支援団体の資料にある「遠回しな言い方」

### 1-1. 自殺予防全般（ゲートキーパー資料など）

- **島根県立心と体の相談センター「ゲートキーパー手帳（島根県版）」（平成30年12月改訂）**：「死にたい」以外の言い方として、次の型を挙げている（要約）。
  - 消えたい／いなくなってしまいたい
  - 自分なんていない方がいい
  - 眠ったまま目が覚めなければいい
  - 誰も知らない所へ行きたい
  - とにかく疲れた
  - 「楽になりたい」
  - また、自殺総合対策大綱の「生きることの阻害要因」の例として育児・介護疲れが載っている。
- **群馬県 広報特集「大切な命を守るためにできること 2」**：自殺の直前のサインのうち発言の例として、消えてしまいたい、「生きていくのが嫌になった」、これ以上耐えられない、自分は誰からも必要とされていない、の4つを挙げている（要約）。
- **札幌市「自殺予防 相談ハンドブック」（平成22年3月）**：はっきりした言い方（死にたい、自殺したい、「死んでしまいたい」）と、具体的な方法をにおわせる言い方を例に挙げている（p.5、p.8）。札幌市の支援者向けページは、はっきり「死にたい」と言う場合は危険が非常に高いとし、「死ぬと言う人は死なない」は誤解だとしている。
- **名古屋市 いのちの支援の資料（高橋祥友『自殺の危険』等にもとづく）**：自殺予防の十箇条の1つに「自殺を口にする」。追い込まれた人の言葉の例として、生きている意味がない、もう何も残されていない、どうでもいい、などの型（要約）。
- **厚労省「まもろうよ こころ」のゲートキーパーのページ、西宮市・東京都の資料**：サインは「自殺をほのめかす」「身辺整理」などの行動の一覧で、具体的な言い回しは載っていなかった。

### 1-2. 育児（産後うつ・虐待の手前）

- **EPDS（エジンバラ産後うつ病質問票、日本語版：岡野ら 1996。厚労省サイト掲載の PDF）**：項目10は「自分自身を傷つけるという考え」が浮かんだかを聞く。産後の健診などで使われる質問。
- **親子のための相談LINE（福岡県・新潟県の案内ページ）**：相談の例として、子育てがつらい、イライラして子どもを叩いてしまいそう、子どもとどう向き合えばいいか分からない、の3つを挙げている（新潟県のページの表現は「こども」）。
- **広島市「『虐待をしてしまう』可能性は誰にでもあります」**：追い詰められた親が「話したいけど話せない」状態にあることに触れている。具体的な言い回しの一覧はない。
- 子どもとの心中（無理心中）を事前に示す言い回しを挙げた公的資料は、**今日は見つからなかった**。

### 1-3. 介護（介護疲れ・介護殺人・心中）

- **nippon.com「日本における介護殺人の現場と今後の課題」（2016年9月15日。湯原悦子氏の分析を紹介）**：
  - 背景は介護疲れ、加害者自身の病気や障害（分析した事例の約3割）、介護離職による孤立など。
  - 「将来を悲観して」の心中・殺害は、事件の時点で介護が差し迫っていたとは限らず、本人が誰にも相談しないため**外から危機が見えにくい**。日記に妻と「共に逝く」と書き残した例が紹介されている。
- **湯原悦子「介護殺人事件に情状鑑定を実施する意義と効果」（日本社会福祉学会 第62回秋季大会）**：事例の加害者は将来を悲観し、支援を断っていた。事件前の言葉の記載はない。
- **広島市「高齢者虐待防止・早期発見マニュアル」**：養護者（介護する家族）のサインの表に、高齢者への話の内容として「早く死んでしまえ」が載っている。
- **厚労省 介護保険最新情報 Vol.1154（2023年6月5日。家族介護者支援マニュアル等）**：介護離職で負担が増え、ストレスから虐待に発展しうると述べている。具体的な言い回しの一覧はない。
- 介護者が心中・殺害の前に口にする言い回しを並べた公的資料は、**今日は見つからなかった**。
  - 「楽にしてあげたい」「一緒に死のう」などは、資料での裏付けが取れていない。挙げるなら**推測**として扱う。

## 2. 今の一覧で拾えていない言い方（部分一致を手で確かめた結果）

資料にある型に、今の一覧を当てはめた（`main.py` 65〜67行の一覧と照らし合わせて確認）。

| 資料にある型 | 今の一覧で当たるか | 理由 |
| --- | --- | --- |
| 死んでしまいたい | **当たらない** | 「死にたい」「死んだほうが」は含まれない |
| 死にたくなる／死にたくて | **当たらない** | 「死にたい」は「死にたく」の中に含まれない |
| 消えてしまいたい／消えたくなる | **当たらない** | 「消えたい」は含まれない |
| いなくなってしまいたい | **当たらない** | 「いなくなりたい」は含まれない |
| 眠ったまま目が覚めなければいい | 当たらない | 該当語なし |
| 生きていくのが嫌／生きている意味がない | 当たらない | 該当語なし |
| 楽になりたい／疲れた／耐えられない | 当たらない | 該当語なし |
| 一緒に逝く（心中） | 当たらない | 該当語なし |
| 早く死んでしまえ（養護者から高齢者へ） | 当たらない | 該当語なし |
| 叩いてしまいそう（漢字） | 当たる | 「叩いてしまい」 |
| たたいてしまいそう（ひらがな） | **当たらない** | ひらがなの登録がない |
| 自分自身を傷つける（EPDS 項目10の型） | 当たる | 「傷つけ」 |
| 一緒に死のう／一緒に死にたい | 当たる | 「死のう」「死にたい」 |

**いちばん大きい穴は、活用の揺れ**（「死にたく」「死んでしまいたい」「消えてしまいたい」「いなくなってしまいたい」）。これらは資料にそのまま出てくる言い方なのに、今の一覧では拾えない。

**今の一覧の誤検知（参考。部分一致を手で確かめた）**：

- 「しのう」は「わたしのうち」に含まれる。
- 「手が出」は「高くて手が出ない」に当たる。
- 「限界」「殴」は、普通の愚痴でもよく出る言葉（推測）。

今の一覧を変えるかは安全審査部の判断。ここでは事実として挙げるだけにする。

## 3. 足す候補の評価（誤検知の多さは、すべて推測）

評価の前提：当たったときの効果は「応援リンクを出さない」と「API が失敗したときのおわびに一文を添える」だけ。普通の返事は変わらない。だから**誤検知の害は小さい**（推測）。ただし、2026-10-12 のリスク2（驚かせるかもしれない）がある。逆に、拾い漏れの害は「危ない状態の人に応援リンクを出す」「おわびだけで相談先が出ない」なので、こちらの方が重い（推測）。

### 3-3. 足さない方がよい（推測）

| 言葉 | 理由（推測） |
| --- | --- |
| `疲れた`、`とにかく疲れた` | 島根県が挙げる型だが、焚き火の愚痴のほとんどに出るはず。足すと応援リンクがほぼ出なくなり、おわびにもほぼ毎回一文が付く |
| `もう無理`、`無理` | 同じく普通の愚痴の言葉 |
| `どうでもいい` | 投げやりな愚痴によく出る |
| `自分なんて` | 自分を責める愚痴によく出る（言葉としては気になる） |
| `死ぬ`（単独） | 「死ぬほど眠い」「死ぬかと思った」 |
| `遠くに行きたい`、`誰も知らない所` | 旅行の話、「逃げたい」の軽い言い方と区別できない |

### 3-4. ひらがな・カタカナ・ネットの書き方（推測）

- 今の一覧はひらがなを一部だけ入れている（しにたい、きえたい、しのう）。3-1 の言葉にも、ひらがなの形を足すのが筋（例：`しにたく`、`きえてしまいたい`、`いなくなってしまいたい` はもともとひらがな）。
- カタカナ（シニタイ、キエタイ）はあまり見かけないと思われる（推測）。足しても誤検知はほぼない。
- ネット上で「死」を「タヒ」と書く言い換えがある（推測。今日は出典で確かめていない）。足すかは安全審査部の判断。
- 一覧を増やす代わりに、照合の前に文字をそろえる（カタカナをひらがなに直すなど）方法もある。ただしコードの変更が大きくなるので、今回は一覧への追加だけで足りる（推測）。
- 根本的な限界：部分一致では、遠回しな言い方や文脈で分かる危なさ（例：「お世話になりました」「全部片付けた」のような身辺整理の話）は拾えない。拾い漏れを前提に、AI の返事に相談先が含まれたら立つフラグ（`SAFETY_REPLY_MARKERS`）と組み合わせて守る今の作りは妥当（推測）。

## 4. line-bot-sdk v3 の振り分けの順番（余力の項目）

- raw.githubusercontent.com、inspector.pypi.io、readthedocs の latest 版の v3 ページは、いずれも取得の許可待ちが時間切れになった。

- 10-12 の結論（旧版は「種別つき → イベントだけ → default」の順。v3 は未確認。テキストなら `on_message` に渡す守りを入れる）は変わらない。

## 会社への示唆（3つ以内）

1. **まず活用の揺れを埋めるのが、効き目が大きく誤検知も少ない。** 資料にそのまま出てくる「死んでしまいたい」「死にたくなる」「消えてしまいたい」「いなくなってしまいたい」が、今の部分一致では拾えない。3-1 の言葉（`死にたく`、`消えてしまいたい`、`一緒に死`、`目が覚めなければ` など。ひらがなの形も）を足す案を、安全審査部に出すとよい。一覧は SAFETY ブロックの外で、テストも足しやすい（推測）。
