# 調査メモ 2026-11-22：乳幼児期のワンオペ育児の「頼れなさ」― 人に頼まない・相談しない理由と、言われてつらかった言葉（当事者ニーズ）／line-bot-sdk の `reply_message` が `_request_timeout` を受けるか（一次情報は読めなかった）

調査部。社長の指示で2つ見た。

- A. 候補欄 11-17 (b) の残り：line-bot-sdk-python v3 の `MessagingApi.reply_message`（`reply_message_with_http_info`）が `_request_timeout` を受けるかを、一次情報で確かめられるか。
- B. 当事者ニーズ：乳幼児を育てる人のワンオペ育児・孤立。10-28（夜中に起きる割合・相談の時間帯）、10-17（言われてつらい言葉）、11-10（男性の当事者）、10-19（ダブルケア）と重ならないよう、**「頼れる人がいても頼まない・相談しない理由」**に絞った。`grep` で「ワンオペ」「頼れ」「説明の手間」を確かめ、この切り口は未調査だった（「ワンオペ」は 10-15 の誤検知の例文と 11-05 の競合記事で出ただけ）。

相談窓口の定期確認（11-21 済み、次は 11-28 ごろ）とモデルの状態（11-20 済み）は今日はやっていない。

## 要点

1. **A は確かめられなかった。** 公式リポジトリの API 説明（`MessagingApi.md`）と 11-17 に使ったコミットのページは、開く許可が下りず読めなかった。読めた公式 README と PyPI のページ（最新 3.27.0、2026-10-27 公開）には `_request_timeout` の記載がない。**`reply_message` が受けるかは今も推測のまま**。`reply()` に付けない今の作りを変える材料は出ていない。
2. **頼れる人がいても頼まない理由は「相手への遠慮」「説明するのが面倒」「自分の責任だと思う」。** アプリ会社の会員調査（415人、2026年4月）で、周りに頼れていない人は25.3%。その理由は、相手が忙しそう・疲れていそうで遠慮する（43%）、事情を説明するより自分でやる方が早い（36%）、相手がどう反応するか心配（29%）、自分がやるべきという責任感・罪悪感（28%）だった（複数回答。この問いに答えた人数は書かれていない）。
3. **数が大きく偏りの少ない調査では、頼れる人がいる人が多い。それでも孤立感は4割を超える。** 横浜市泉区の0〜3歳の親の調査（882人、2024年）では、困ったときに頼れる人がいる人が76.6%、親族に頼れる人が1人以上いる人が95.7%だった。一方で、人とのつながりがないと感じることが「ある」人は42.5%、子育て中によくイライラする人は70.6%だった。**頼れる人がいることと、孤立を感じないことは別**。
4. **経済的に苦しい家庭では「相談しても仕方ない」が多い。** 0〜3歳の子がいる低所得の家庭（回答480人、母親97.3%、ひとり親71.9%、2024年）で、一人で子育てをして孤独を感じることが「よくある」「ときどきある」人は合わせて約72%。乳幼児健診で相談しなかった人の54.0%が「相談しても仕方ない」と答えた。自由記述には、軽く扱われた・責められたと感じた言葉が並ぶ（下の 2-3）。

## 2. B：乳幼児期のワンオペ育児の「頼れなさ」

### 2-1. 頼れる人がいても頼まない理由（カラダノート調査）

株式会社カラダノートが自社のメールマガジン会員に聞いた調査（2026年4月2〜12日、415人、2026年4月21日発表）。

- 周りに頼れているかを聞くと、「あまりできていない」21%、「全くできていない」4.3%で、合わせて25.3%。
- 頼れていない人に理由を聞くと（複数回答）：パートナーが忙しそう・疲れていそうで遠慮する 43%、事情を説明する手間を考えると自分でやってしまう 36%、相手が不機嫌になったり戸惑ったりしないか心配 29%、自分がやるべきという責任感・罪悪感 28%。
- この会社は、手伝ってもらえる環境があるのに遠慮や疲れ、説明の手間で頼めない状態を「サイレント・ワンオペ」と名付けている。原文：「周囲に頼れる環境があるにもかかわらず」。
- 注意：**会社が自分で付けた呼び名**で、決まった用語ではない。会員の調査なので全体の様子とは限らない。子の年齢・回答者の性別・設問の文言・理由の問いに答えた人数は書かれていない。

### 2-2. 数の多い自治体調査（横浜市泉区）

横浜市泉区「子育てに関するアンケート調査 報告書」（2025年10月）。0〜3歳の子を育てる区内の家庭が対象で、主に世話をしている人 593人と、それを支える人 289人の計882人（調査は2024年5月1日〜9月30日、健診の案内と一緒に配布）。

- 困ったときに頼れる人がいる 76.6%、相談できる人がいる 76.3%（p.34）。親族に頼れる人が1人以上いる 95.7%、友人では 67.8%（p.40）。
- それでも、人とのつながりがないと感じることが「ある」42.5%、取り残されていると感じる 22.9%、孤立していると感じる 23.1%（p.38）。主に世話をしている人の方が7〜8ポイントほど高い。
- 子育て中によくイライラする 70.6%（p.24）。原因の1位は子どもが言うことを聞かない（23.0%）、次がパートナーのこと（17.0%）、自分の時間がない（13.5%）（p.26）。
- 子育ては思っていたより大変 89.2%（p.24）。
- 子育ての情報はSNSから得る人がいちばん多い（45.4%、p.18）。相談の手段の好み（LINE など）は聞いていない。時間帯も聞いていない。

### 2-3. 経済的に苦しい家庭（セーブ・ザ・チルドレン）

セーブ・ザ・チルドレン・ジャパン「乳幼児のいる低所得子育て世帯への調査」（2025年2月）。同団体の支援を受けた家庭に聞いたもので、全体の様子ではない（2024年6月22日〜8月6日、1,873件に送って480件回答）。

- 一人で子育てをして孤独を感じることが「よくある」34.8%、「ときどきある」37.5%（p.4・p.20）。
- 乳幼児健診で、相談しようと思わなかった 24.6%、相談できなかった 6.5%（p.23）。相談しなかった人では、相談しても仕方ない 54.0%、お金や暮らしの悩みは話しにくい 59.5%（p.23）。
- 自由記述（p.22・p.24・p.25。個人が分からない形で要約）：支援者に相談したら理由を軽く扱われたと感じた、親族に「産むと決めたのは自分なのだから」という趣旨のことを言われた、「あなたより困っている人はたくさんいる」と比べられた、という声。訪問が役に立たなかった人の 10.6% が「責められたと感じた」と答えた（p.22）。
- 欲しい支援の上位は、おむつなどの物の支援や手当の増額で（86.5%・78.8%など）、親どうしで話す機会は 16.0% だった（p.24）。

### 2-4. 補足の数字

- 6歳未満の子がいる夫婦の1日の家事・育児などの時間（2021年、総務省統計局「統計Today No.190」）：夫 1時間54分、妻 7時間28分（p.2）。育児だけでは、共働きで夫 1時間03分・妻 3時間24分（p.4）。差は縮まっているが、まだ大きい。
- 株式会社one の調査（2026年4月、18歳以上の女性1,000人、デイリースポーツの記事）：令和に子育てをしている人の53.2%が、子育てで孤独を感じることが「たまに」「よく」ある。昭和50〜63年に子育てをした人は36.6%。記事で読んだだけで、調査の本文は見ていない。**女性だけの調査**。

### 2-5. 焚き火に当てはめると（推測を含む）

- 頼まない理由の上位が「相手への遠慮」と「説明の手間」だった。焚き火は相手が疲れることがなく、事情を一から説明しなくてもいい。この2つの壁が低い場所になりうる（**推測**。焚き火の利用者に聞いたわけではない）。
- 今の PERSONA 55行は「2〜3往復したら、質問を1つだけ」で、事情を細かく聞き出す作りではない。この点は今の作りと合っている。
- 「あなたより困っている人がいる」と比べる、「自分で決めたことでしょ」と言う、というのはつらい言葉の典型。PERSONA 48行（説教しない・正論で諭さない）の範囲だが、「よそと比べない」ははっきりとは書かれていない（PERSONA は 10-23 から休み中なので、候補として記録するだけ）。
- 孤立感は「頼れる人がいない」人だけのものではなかった（泉区 2-2）。広報で「頼れる人がいないあなたへ」と書くと、頼れる人がいても頼めない人には届きにくい（**推測**）。

## 会社への示唆（3つ以内）

1. **企画部へ：コード候補なし。`reply()` はそのまま。** `reply_message` が `_request_timeout` を受けるかは、今日も一次情報で確かめられなかった。候補 11-17 (b) は「オーナーの返事待ち」のまま据え置き、`docs/owner_todo.md` の「（2026-11-19 追加・任意・急がない）」に新しいお願いは足さなくてよい。調査部が `MessagingApi.md` を読めるようになれば、もう一度確かめられる（社長の判断）。
2. **企画部へ（PERSONA 再開時の候補。未審査）：「くわしく説明させない」「よそと比べない」。** 頼まない理由の上位が「説明の手間」（36%）と「相手への遠慮」（43%）で、「あなたより困っている人がいる」と比べる言葉がつらかったという声もあった。PERSONA が再開したら、「事情をくわしく話さなくていい。ひとことの愚痴でもそのまま受け止める」「よその人や家庭と比べない」を、48行・55行のそばに足すたたき台にできる（文言は安全審査部に回す）。今の 55行（質問は1つだけ）はこの材料と合っているので変えない。
3. **広報部へ：「頼れる人がいても頼めない」を言葉にしてよい。ただし数字と呼び名に注意。** 「家族はいるけど、疲れてるのが分かるから頼めない」「説明するより自分でやった方が早い」といった気持ちは、出典に裏付けがある。数字を使うなら出典を添え、母集団の偏り（アプリの会員・支援を受けた家庭・女性だけ）を書く。「サイレント・ワンオペ」は一社が付けた呼び名なので、決まった用語のように使わない。「ママ」だけに向けた書き方にしない（11-10 の男性の当事者）。「孤独を解消」「頼れる場所」のような効き目を約束する言い方もしない。
