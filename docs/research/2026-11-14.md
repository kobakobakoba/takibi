# 調査メモ 2026-11-14：仕事と介護を両立する人（ビジネスケアラー・ワーキングケアラー）は、職場で言えているか・眠れているか・誰に吐き出しているか（当事者ニーズ）／介護者向け LINE の AI（競合）

調査部。当事者ニーズは 10-17（言われてつらい言葉）、10-19（ダブルケア）、10-28（夜間）、11-08（年末年始）、11-10（男性）、11-11（医療的ケア児の親）、11-12（ヤングケアラー）で扱った。11-10 の示唆2「仕事と世話の両立のしんどさ」は材料が父親の悩みと 2017 年の統計だけだったので、今日は**働きながら介護している人**に絞って一次資料を探した。

## 結論を先に

1. **職場に介護の相談をする人は少ない。** 厚労省の委託調査（2024年12月）で、介護の相談相手に「勤務先」を選んだのは正社員で 11.9%。「家族・親族」40.5%、「ケアマネジャー」32.5% より少なく、「誰にも相談していない」も 8.8% いた。
2. **職場から何の助けも感じていない人が多い。** 同じ調査で、正社員の 59.6%（図表では 59.0%）が「職場から特に情報提供やサポートは受けていない・助けられたと感じない」。有期・無期の契約の人では 7割台。
3. **働きながら介護している人は眠れていない・孤独を感じやすい。** マイナビの調査（2026年4月、7,930人）で、平日の睡眠が6時間未満の人は介護している人 29.2%、していない人 18.9%。孤独・孤立を感じる人は 35.2% と 21.9%。介護している人の孤独の理由の3番目が「相談できる人がいない」24.9%。
4. **競合：在宅介護者向けの無料・24時間の LINE の AI「ヨルニモ」**（エーザイグループ、2025年10月開始と報道）。会話をもとに月ごとの振り返りを作り、利用者に合わせて学ぶと説明しており、焚き火の「残さない」とは反対の作り。
5. **SAFETY の案内先の要修正：なし**（今日は窓口の確認はしていない。窓口が古くなっている情報にも行き当たらなかった）。

## 1. 職場に言えているか・相談先（一次資料）

厚生労働省 委託調査「令和6年度 仕事と介護の両立等に関する実態把握のための調査研究事業」労働者調査 結果の概要（三菱UFJリサーチ＆コンサルティング、2025年3月）。インターネット調査（2024年12月5〜12日）で、正社員 1,100人、無期契約 435人、有期契約 430人、離職者 759人。

- 介護の相談相手（Q24_1、複数回答とみられる。設問の形は概要からは確かめていない）：

  | 相談相手 | 正社員 | 無期 | 有期 | 離職者 |
  |---|---|---|---|---|
  | 家族・親族 | 40.5% | 39.1% | 43.5% | 32.5% |
  | ケアマネジャー | 32.5% | 31.7% | 37.2% | 22.4% |
  | 勤務先 | 11.9% | 7.4% | 7.9% | 13.8% |
  | あてはまるものはない | 23.1% | 25.3% | 20.7% | 26.9% |
  | 誰にも相談していない | 8.8% | 9.2% | 9.3% | 5.4% |

- 職場に介護の相談をしやすいか（Q28）で「そう思う」「まあそう思う」の合計は、正社員 47.8%、無期 36.1%、有期 36.8%。
- 職場から受けたサポート（Q26_1）で「特に受けていない・助けられたと感じない」は正社員 59.6%（本文）／59.0%（図表）、無期 76.6%、有期 75.6%。
- 今の勤務先で介護しながら働き続けられるか（Q45）で「おそらく続けられない」「続けられない」の合計は、正社員 24.9%。
- この概要には、睡眠・ストレス・心身の負担の設問はなかった。

**注意（数字の食い違い）**：第一生命経済研究所のコラム（2026-02-19）は、同じ調査を出典に「勤務先」を 4.1% としている。今日読んだ労働者調査の概要では、どの区分にも 4.1% は見つからなかった（別の集計か、別の設問の可能性。推測）。焚き火で数字を使うときは、上の概要の表の数字を、区分（正社員など）をつけて使う。

経済産業省（2024-03-26 公表）：2030年にビジネスケアラーは約318万人、経済損失は約9兆円と試算し、「仕事と介護の両立支援に関する経営者向けガイドライン」を出した。同ガイドラインの**案**の PDF には、従業員はキャリアへの影響を心配して介護の状況を言いにくい、社内外の専門窓口を置く企業は約1割、とある（案の版で、公表版で同じかは確かめていない）。

## 2. 眠れているか・孤独か

マイナビ「ワーキングケアラー」の調査（公開 2026-07-22。2026年4月8〜20日、20〜60代の就業者 7,930人、ウェイトバックあり）：

- 働く人のうち介護している人は 6.5%。
- 平日の睡眠6時間未満：介護している人 29.2%／していない人 18.9%。休日：15.1%／8.2%。
- 私生活で孤独・孤立を感じる：35.2%／21.9%。
- 介護している人の孤独・孤立の理由：お金の不安 30.3%、生きがいを感じられない 26.2%、相談できる人がいない 24.9%。
- 夜間の介護（夜中に起きるか）の数字は記事になかった。

参考（小さな調査）：労務SEARCH 編集部のアンケート（2025年2〜3月、働きながら介護する69人）では、両立を負担に感じる人が 85.5%、介護を理由に辞めることを考えたことがある人が 56.5%。69人のネット調査なので、全体を表す数字としては使わない。

## 3. 制度の動き（2025年施行の改正育児・介護休業法）

厚労省の両立支援のサイト（ページの更新 2026-11-05、メタ情報）では、2025年4月施行の改正点として、介護離職を防ぐための雇用環境の整備、介護に直面したと申し出た人への個別の周知と意向確認、40歳など早い段階での情報提供、介護休暇の要件の緩和、の4つを挙げている。どれが義務でどれが努力義務かは、このページからは確かめられなかった。

推測：企業から「制度の説明」は増えていくが、上の 1 のとおり、制度を知っていても職場に介護の気持ちまで話す人は少ない。焚き火が受け止めたいのは制度の手前の「言えない疲れ」のほう。

## 4. 競合：介護者向け LINE の AI「ヨルニモ」（報道）

ASCII（2025-10-07 の記事）によると：

- 提供元はテオリア・テクノロジーズ（エーザイグループ）。在宅で介護をしている人向け。第1段階は LINE 版、アプリ版は 2026年1月予定とされていた。
- 無料、24時間の LINE チャット。
- 会話の記録をもとに月ごとの振り返りのレポートを作り、会話を重ねて感情や介護のスタイルを学んでいく、と説明している。保存期間・データの扱い・危ないときの対応は記事に書かれていない。
- 今後は企業の人事部や社会福祉法人との連携で広げる予定。

焚き火との違い（推測）：ヨルニモは「覚えて振り返る」ことを価値にしており、焚き火は「残さず燃やす」ことを価値にしている。同じ「夜・LINE・介護者」でも約束が逆なので、焚き火の説明では「残さない」を軸にするのが分かりやすい。ただしヨルニモの今の提供状況（アプリ版が出たか、続いているか）は今日は確かめていない。広報で名前を出して比べない（11-05 の申し送り「他より安全と書かない」と同じ）。

## 5. 焚き火に当てはめると（コード確認＋推測）

- `main.py` 41行は「育児と介護が重なっている人」「何人もの家族を同時に世話している人」を受け止める1行。**仕事との両立には触れていない**（今日 `main.py` を読んで確認）。
- 11-10 の示唆2（父親の悩みの上位が仕事、男性介護者の約3人に2人が働いている）に、今日の「職場に相談するのは正社員で 11.9%」「職場から助けを感じない 59.6%」「睡眠6時間未満 29.2%」が加わり、**仕事と介護の両立のしんどさを受け止める一文**の材料はそろってきた（推測）。ただし PERSONA は 10-23 から休み中。
- 気をつけること（推測）：働きながらの介護の話に、AI が休業制度や会社への相談を勧めはじめると「アドバイスは聞かれたときだけ」（11-05）とずれ、労務・法律の助言にも近づく。足すなら「職場では言えない疲れ」を受け止める方向にとどめ、制度の説明はしない形がよい。

## 会社への示唆（3つ以内）

1. **PERSONA を再開する日の候補に「職場では言えない疲れ」を受け止める一文を残す**（候補。実装は企画部・安全審査部の判断、PERSONA は休み中）。根拠は「勤務先に相談する正社員 11.9%」「職場から助けを感じない 59.6%」「睡眠6時間未満 29.2%」。制度や会社への相談を勧める形にはしない（11-05 の「アドバイスは聞かれたときだけ」と、労務の助言に近づくのを避けるため）。今日すぐのコード候補はない。
2. **競合の「ヨルニモ」は、同じ LINE・24時間・介護者向けで「覚えて振り返る」型。** 焚き火の違いは「残さない」で、その説明は今の `HELP_TEXT` にもうある。広報部は競合の名前を出して比べず、「職場でも家でも言えない疲れを、残さず燃やす」の方向で書ける（推測）。数字を使うなら、区分（正社員など）と出典をつける。「勤務先 4.1%」は使わない。
3. **第3段階（法人向け）の材料**：企業は 2025年から介護の情報提供などに取り組むことになり、介護者向け AI も企業の人事部と組む動きがある（報道1本）。焚き火が法人向けに出るなら「会社に知られずに吐き出せる」ことが価値になりうるが、10-30 の論点（記録と報告の前提とぶつかる）は変わらない。オーナーが第3段階を考えるまで寝かせる材料。
