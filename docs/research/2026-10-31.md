# 調査メモ 2026-10-31：Anthropic の利用ポリシー改定（2026-11-12 施行）は焚き火に何を求めるか ― 「AIであることの明示」と「未成年」を中心に

調査部。これまで調べていなかった「焚き火が使っている AI の提供元（Anthropic）のルール」を調べた。10-08 に新しい利用ポリシーが発表され、**2026-11-12 に施行**される（あと12日）。あわせて、AI の話し相手・相談ボットへの国内外の動きを少しだけ見た。窓口の全体確認は 11-03 予定なので、今日はしていない。

## 結論を先に

1. Anthropic の利用ポリシーは、**消費者向けのチャットボットに「AIと話している」ことの明示を求めている**。新しい版（11-12 施行）では、明示の場所は「各チャットの始め」か「製品の画面」のどちらか。焚き火の固定文で「AI」と書いてあるのは「使い方」（`HELP_TEXT`）だけで、**友だち追加のあいさつ（`WELCOME`）には「AI」の語がない**（`main.py` を読んで確認）。
2. **未成年**（国を問わず18歳未満）が直接使う製品には、追加のガイドライン（年齢確認など）が求められる。焚き火は大人向けだが、どこにも「18歳以上」とは書いていない。ヤングケアラーが使う可能性はある（推測）。
3. 焚き火の吐き出しは、今の作り（診断しない）なら「高リスク用途」には当たらない見込み（推測）。ただし**心の病気の評価・診断は「高リスク（医療）」に入る**ので、「うつ度チェック」のような機能を足すと、資格のある人の確認などが要る。
4. 国内では厚労省が、**AIが対応していると明示したうえで** SNS 相談の一部を AI が担うモデル事業を来年度から始める方針（報道）。

**要修正（相談窓口）：なし**（今日は窓口を調べていない。11-03 の定期確認で扱う）。

## 1. Anthropic 利用ポリシー（Usage Policy）の新しい版

### 1-1. 施行日（事実）

- 新しい版の発表は 2026-10-08、施行は **2026-11-12**（Anthropic の公式ニュース、利用ポリシー本文の「Effective」表示）。
- 前の版は 2025-09-15 施行。施行日以降も使い続けると新しい条件に同意したとみなされる、と Bedrock 利用者向けの通知を紹介した記事にある（クラスメソッド。焚き火は Bedrock ではなく API 直接だが、考え方は同じと見込む。推測）。
- 主な変更点は、選挙・偽装キャンペーン・兵器・監視・機器の制御・高リスク用途の対象の整理・Claude への悪質な言動の禁止など。**焚き火に直接関係しそうなのは下の 1-2〜1-5 だけ**。

### 1-2. 消費者向けチャットボットの「AIであることの明示」（事実）

- 本文：外部の利用者と直接やりとりする消費者向けチャットボットは、相手が人ではなく AI と話していることを伝えなければならない。提供元（Anthropic・Claude・モデル名）を名乗る必要はない。
- 明示の時期は、少なくとも「at the beginning of each chat session or in the product interface」（各チャットの始め、または製品の画面）。
- 前の版（2025-09-15 施行、今も有効）でも同じ明示は求められており、時期は「各チャットの始め」だけだった。「または製品の画面」は新しい版で足された、と第三者の差分記録にある（Anthropic の旧版本文では確かめられていない）。

#### 焚き火に当てはめると（コードを読んで確認＋推測）

- `WELCOME`（友だち追加のとき）：「ここは育児・介護の愚痴を燃やす焚き火です」で始まり、**「AI」の語はない**。
- `HELP_TEXT`（「使い方」と送ったとき）：「AIが短く受け止めます」「会話はAIの提供元（Anthropic社）に送られます」とある。ただし利用者が自分で頼まないと出ない。
- `PERSONA`：「あなたはLINEの「焚き火」です」。AI であることを隠せという指示はなく、聞かれれば AI と答えるはず（推測。本番の返事は会社から見えない）。
- LINE 公式アカウントのプロフィール・ステータスメッセージ・リッチメニュー（＝製品の画面に当たりうるもの）に AI と書いてあるかは、**会社からは見えない**（オーナーの管理画面の設定）。
- 評価（推測）：焚き火の「チャット」は「燃やす」か1時間で区切られ、そのたびに始まりの固定文は出ない。新しい版の「製品の画面」で満たすには、少なくとも友だち追加のときに必ず目に入る `WELCOME` か、LINE のプロフィールに「AI」とあるのがわかりやすい。どこまでで足りるかは Anthropic の解釈次第で、会社では決められない。

### 1-3. 未成年（事実）

- 本文：未成年は**国を問わず18歳未満**。未成年が API を使った製品と直接やりとりできるようにする組織は、サポート記事の追加ガイドラインと関係する法令に従う。
- そのガイドライン（2024年5月の導入時の報道）：年齢確認の仕組み、内容のチェック・フィルタ、未成年向けの安全なシステムプロンプト、守っていることの公表などを求め、Anthropic が定期的に確かめるとしていた。
- 今のガイドライン本文は今日読めなかった（アクセスの許可が下りず。下の「確認できなかったこと」）。関連するサポート記事（子どもの安全、2026-06-26 更新）も「未成年が直接使えるなら年齢確認を含むガイドラインに従う」と案内している。

#### 焚き火に当てはめると（推測）

- 焚き火は「育児・介護をしている人」向けで、子ども向けではない。ただし `PERSONA` は「子どもや親・家族の世話をしている人」と行為で書いており（10-21 の変更）、親やきょうだいの世話をしている中高生が使うことはありうる。
- 年齢確認や利用の記録は、約束2「保存しない」とぶつかりやすい。会社だけで「未成年も使える作り」に進むのは難しい。
- 逆に「18歳以上向け」と書くと、ヤングケアラーを門前払いすることになる。どちらにするか、未成年が来たときにどこを案内するかは**オーナーの判断**。

### 1-4. 高リスク用途（事実＋推測）

- 高リスク（個人への助言・判断）の11分野のうち「医療」に、**心の病気の評価・診断・治療**が入る。高リスクに当たると、資格のある人が中身を確かめてから届けること、AI を使ったと伝えることが要る。
- 除外の例に「睡眠・ストレスなどの一般的なウェルネス情報」がある。「気持ちを受け止める会話」は除外の例にも高リスクの例にも書かれていない。
- 焚き火は SAFETY 63行で診断・判断をしないとしており、今の作りは高リスクに当たらない見込み（推測）。**「うつ度チェック」「疲れ度の判定」などを足すと高リスク側に寄る**（推測）。

### 1-5. そのほか（事実＋推測）

- 新しく「Claude への、続けざまで必要のない悪質・残酷な言動」が禁止に加わった。Anthropic は、ふつうの不満やいら立ちは対象外で、極端な場合だけと説明している。焚き火の吐き出しは家族や毎日への愚痴で、AI への攻撃ではないので、影響はない見込み（推測）。
- 「許可のない方法で Claude へのアクセスを転売・中継する」ことの禁止が明記された。焚き火は自分の API キーで自分のボットを動かしているので当たらない見込み（推測）。
- 感情を推定する仕組み（emotion recognition）を作ることは、医療・安全の理由を除いて禁止（監視の節）。焚き火は気持ちを受け止める返事を作るだけで、感情を判定・記録する仕組みはない（`SAFETY_USER_WORDS` は危ない言葉の一致を見るだけ）。将来「気分の記録」「感情の分析」を足す場合は、この節と約束2の両方に当たる（推測）。

## 2. AI の話し相手・相談ボットへの国内外の動き（参考）

- **国内**：厚労省が、SNS 相談を担う民間団体と組み、**AI が対応していることを明示したうえで**相談員のやりとりの一部を AI が担う仕組みを、来年度からモデル事業として検証する方針（2026-10-24、共同通信配信）。同じ記事は、海外で AI に相談していた若者が亡くなり遺族が開発企業を訴えた例にも触れている。
- **米カリフォルニア州（SB 243、2026-01-01 施行）**：社会的・感情的なニーズに応える「コンパニオン・チャットボット」に、人と誤認されうる場合の AI の明示、未成年と分かっている相手には AI であることと休憩の呼びかけ（初期設定で3時間ごと）、自殺・自傷の話が出たら危機の窓口を案内する手順を持ち、その中身を公表すること、などを求める。2027-07-01 から、窓口を案内した件数などの年1回の報告も始まる。焚き火は日本向けで直接は当たらないが（推測）、「AIの明示」「危ないときの案内」「手順の公表」が業界の標準になりつつある流れとして参考になる。

## 会社への示唆（3つ以内）

1. **「AIであることの明示」を、友だち追加のあいさつにも入れることを検討する（企画部へ。11-12 の施行前が目安）**。今は「使い方」でしか AI と言っておらず、Anthropic の求める「各チャットの始め／製品の画面」に足りているか心もとない（推測）。`WELCOME` の1文目に「返事はAIが書きます」程度の短い語を足す案は小さく戻しやすい。10-28 の `WELCOME` の言いすぎを見張るテストと、夜中の呼びかけを増やさない申し送り（AI の明示は呼びかけではない）に注意。あわせて、LINE のプロフィールなどに AI と書いてあるかの確認をオーナーにお願いする（会社から見えない）。
2. **未成年（18歳未満）が使ったときの扱いはオーナーの判断に回す**。Anthropic は未成年が直接使う製品に年齢確認などを求めており、「保存しない」とぶつかりやすい。一方で「18歳以上向け」と書けばヤングケアラーを締め出す。会社は作らず、`docs/owner_todo.md` の判断待ちとして載せるのがよい（推測）。
3. **「心の状態を判定する」機能は足さない方針を守る**。うつ度チェック・感情の分析・気分の記録は、Anthropic の高リスク（医療）や感情推定の禁止、約束2に同時に当たりうる。広報部も「メンタルチェック」「心の状態がわかる」とは書かない。
