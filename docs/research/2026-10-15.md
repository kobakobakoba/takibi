## 1. 文字をそろえる方法について確認できたこと（事実）

### 1-1. Python 標準の `unicodedata.normalize("NFKC", ...)` でそろうもの・そろわないもの

- NFKC にかけると、半角カナは全角カナに、全角英数字は半角に変わる。半角の濁点（ﾞ）は前の文字とくっついて1文字（例：ﾃﾞ→デ）になる。㌔ のような1文字の単位もカタカナに開かれる。（tex2e の解説記事の実例）
- **カタカナはひらがなにならない。** 同じ記事の実例でも、変換後はカタカナのまま。（tex2e）
- 日本語の辞書（mecab-ipadic-neologd）の前処理の手順でも、半角カナ→全角カナ、全角英数→半角、長音記号のたぐいを「ー」に統一、波ダッシュ（〜）の削除、かなどうしの間の空白の削除、を行っている。**カタカナ→ひらがなの変換は手順に入っていない。**（neologd の wiki）
- `unicodedata` は Python の標準ライブラリで、`requirements.txt` に足すものはない。ただし Python 公式ドキュメントのページは今日は取得できなかった（「確認できなかったこと」）。

### 1-2. カタカナ→ひらがなは、文字の番号を一定の数だけずらせばよい

Unicode 18.0 の文字表で確認した。

| | ひらがな | カタカナ |
| --- | --- | --- |
| 小さい「あ」 | ぁ U+3041 | ァ U+30A1 |
| 「ゔ」「ヴ」 | ゔ U+3094 | ヴ U+30F4 |
| 小さい「か」「け」 | ゕ U+3095、ゖ U+3096 | ヵ U+30F5、ヶ U+30F6 |

- ひらがなは U+3041〜U+3096、カタカナは U+30A1〜U+30F6 が切れ目なく並び、**どちらも86文字で、番号の差はちょうど 0x60**（文字表の番号から計算）。この範囲だけを 0x60 引けば、カタカナがひらがなになる。
- **範囲に入れてはいけない文字**：ヷヸヹヺ（U+30F7〜30FA。対応するひらがながない）、・（U+30FB）、ー（U+30FC。名前のとおり**カタカナとひらがなで共通の長音記号**なので、そのままにする）、ヽヾ（U+30FD〜30FE）。（Unicode の文字表）
- 公開されている変換スクリプト（olsgaard の Japanese_nlp_scripts）も、対応表を作って `str.translate` で置き換える方法を使い、「ー」はわざと表から外している。ヴ・ヵ・ヶ は ゔ・ゕ・ゖ に対応させている。半角カナは表に入っていないので、そのままでは変換されない（推測。表の中身から）。→ **先に NFKC で全角にしてから、カタカナ→ひらがなにする順番が要る。**

## 2. 焚き火に当てはめると（ここからは推測を含む設計の材料。決めるのは企画部・開発部・安全審査部）

### 2-1. 変更の形（案）

```python
import unicodedata
_KATA2HIRA = {c: c - 0x60 for c in range(0x30A1, 0x30F7)}  # ァ〜ヶ → ぁ〜ゖ（ー・ヷ〜ヺ・ヽヾは変えない）

def fold_kana(text: str) -> str:
    """照合のためだけに文字をそろえる（半角カナ→全角→ひらがな）。元の文は変えず、どこにも残さない"""
    return unicodedata.normalize("NFKC", text).translate(_KATA2HIRA)
```

- 照合の2か所（249行・289行）を `fold_kana(text)`／`fold_kana(msg["content"])` に変えるだけ。**Claude に送る文・履歴に入れる文は元のまま**（そろえた文はその場の判定にだけ使い、保存しない・ログに出さない）。
- 行数の見積もり：`main.py` はおおむね7行（import 1、表と関数 4〜5、照合2か所の書き換え）。テストを足しても合計40行前後で、100行の上限に収まる（推測）。
- 一覧の50語は**一字も変えない**。SAFETY ブロック、`SAFETY_REPLY_MARKERS`、モデル、`max_tokens`、`requirements.txt` にも触らない。
- 2か所のうち片方だけ変えると、「普段は旗が立つのに、AI が失敗したときのおわびには一文が付かない」というずれが出る。**必ず2か所そろえて変える**（コードを読んでの指摘）。

### 2-2. 拾えるようになる言い方（今の一覧に当てはめて手で確認）

| 送られた文 | 今 | そろえた後 | 当たる語 |
| --- | --- | --- | --- |
| シニタイ | × | ○ | `しにたい` |
| ｼﾆﾀｲ（半角） | × | ○（NFKC で全角→ひらがな） | `しにたい` |
| 死ニタイ（漢字＋カタカナ） | × | ○（→「死にたい」） | `死にたい` |
| キエタイ／キエタクナル | × | ○ | `きえたい`／`きえたくな` |
| モウシニタクナル | × | ○ | `しにたく` |
| タタイテシマッタ | × | ○ | `たたいてしま` |
| シンジャイタイ、キエチャイタイ | × | ○ | `しんじゃいた`、`きえちゃいた` |
| イナクナリタイ | × | ○ | `いなくなりたい` |

- **効くのは、ひらがなの形が一覧にある17語だけ**（しにたい、きえたい、しのう、しにたく、しんでしまいたい、きえてしまいたい、きえたくな、きえたくて、いなくなりたい、いなくなってしまいたい、たたいてしまい、たたいてしま、たたきたく、きえてなくなりたい、しんじゃいた、きえちゃいた、たたいちゃい）。
- 漢字だけの語（`自殺`、`虐待`、`限界`、`殴`、`首を絞め`、`無理心中` など）はカタカナで書かれても拾えないまま。例：「ジサツ」は「じさつ」になるが、一覧に `じさつ` はない。
- 一度そろえる仕組みが入れば、**今後ひらがなの語を足すたびに、カタカナ・半角カナの形も自動で拾える**。カタカナ形を1語ずつ足す（17語、一覧が67語になる）より、一覧を大きくしない方針に合う（推測）。

### 2-3. それでも拾えない書き方（そろえる処理の外）

- 伸ばし棒や記号を挟む書き方：「しにたーい」「シニターイ」「し に た い」「死に…たい」。空白や「ー」を消す処理は、普通の文を思わぬ形でくっつけて誤検知を増やすおそれがあるので、今回の案には入れない方がよい（推測）。
- ネットの言い換え「タヒ」：今日も**公的資料や研究で裏付けを見つけられなかった**（下の「確認できなかったこと」）。仮に使われていても、カタカナ→ひらがなでは「たひ」になるだけで拾えない。足すかどうかは別の話として残す。
- 当事者がカタカナで「シニタイ」と書くことがどのくらいあるかは、**出典で確認できなかった**。研究（影山・森口 2026）でも検索語は「死にたい」と「しにたい」の2つの書き方だけを使っており、カタカナは扱っていない。効き目の大きさは不明で、「起きたときの守り」と書くのが正確（推測）。

### 2-4. 新しく増える誤検知（推測）

- 増えるのは「**今ひらがなで書くと当たる普通の文を、カタカナで書いたとき**」だけ。例：「ホシノウタ（星の歌）」→「ほしのうた」が `しのう` に当たる、「ワタシニタイシテ」→ `しにたい` に当たる。どちらも、ひらがなで書けば今すでに当たる種類で、新しい種類の誤検知ではない。
- 外来語（カタカナ語）に `しのう`・`しにたい`・`きえたい`・`たたきたく` などの並びが入る例を手で探したが、思いつかなかった（推測）。
- NFKC は全角英数字を半角にするが、一覧に英数字の語はないので影響しない。普通の漢字・ひらがなは NFKC で変わらないはず（推測。tex2e の例では、変わったのは丸数字・全角記号・単位の1文字・半角カナ・全角英数だった）。
- 当たったときの効果は今までどおり「応援リンクを出さない（未設定）」「AI が失敗したときのおわびに 110番・119番の一文を添える」だけ。普段の AI の返事は変わらない。

### 2-5. テストの材料（開発部向け。推測を含む）

- 拾える文（今の一覧では当たらず、そろえた後に当たる）：「シニタイ」「ｼﾆﾀｲ」「死ニタイ」「キエタクナル」「タタイテシマッタ」。変更前のコードで全部落ちることを確かめられる（一覧にカタカナがないので、原理上落ちる）。
- 普通の文（そろえた後も当たらない）：「ワンオペで疲れた」「ストレスがたまる」「ケアマネに電話した」「ミルクを作った」など、カタカナを含む愚痴。`ORDINARY_COMPLAINTS` に足すと、そろえる処理が普通のカタカナ語で誤検知しないことを守れる（手で照らした範囲では当たらない）。
- 一覧の守り：「一覧の各語は、`fold_kana(語) == 語`（そろえても変わらない）」をテストにすると、将来だれかがカタカナや半角の語を一覧に足して「一生当たらない語」になる事故を防げる。

## 会社への示唆（3つ以内）

1. **「照合の前に文字をそろえる」は、今日1つの小さな改善として選べる大きさ。** 標準ライブラリだけで、`main.py` おおむね7行（NFKC で半角カナを全角に → U+30A1〜U+30F6 を 0x60 ずらしてひらがなに）。一覧の50語は変えずに、ひらがなの形がある17語でカタカナ・半角カナも拾える。足す変更（安全側）なので、`しにたく` の絞り込み（狭める変更）とは別の日に出せる。ただし、カタカナで書く人がどれくらいいるかは出典で確かめられなかったので、日報には「起きたときの守り」と書く（推測）。
2. **作るなら守ることは3つ。** (a) 照合の2か所（249行・289行）を必ずそろえて変える。(b) そろえた文は判定にだけ使い、Claude に送る文・履歴・ログは元のまま。(c) 「ー」・空白・記号は消さない（誤検知が増えるおそれ。推測）。テストで「一覧の各語はそろえても変わらない」を守ると、カタカナの語を足して一生当たらない事故を防げる。
3. **相談窓口は今日も要修正なし。** 189 は24時間・無料で「子どもに当たってしまう」悩みも受けると自治体が案内中。親子のための相談LINE は東京都で平日23時・土日祝17時までなので、「夜間は 189 を先に」というオーナーへの提案は今も妥当。
