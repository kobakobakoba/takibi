# 調査メモ 2026-10-21：PERSONA 39行「子どもや親・家族の世話を毎日がんばっている人です。」の見直し（第2弾 (c) の裏付け）

調査部。PERSONA 第2弾で残る (c) の材料を集めた。39行のうち「毎日」と「がんばっている」の2語が、実際の利用者の姿と公的資料の勧める接し方に合っているかを調べた。

選んだ理由：バックログで今すぐ出せる体験の改善は (c) だけで（ほかは安全審査部・オーナーの判断待ち）、(c) は「急がない」とされたまま根拠が 10-17 の1件しかなかったため。相談窓口の全体の定期確認は 10-15 に済んでおり、今日は行っていない（下の 4）。

前提：
- `main.py` 39行は `相手は、子どもや親・家族の世話を毎日がんばっている人です。`（今日 `main.py` を読んで確認。40行はダブルケアの1行、49行は「がんばって」と励まさない1行）。
- 個人の投稿は使っていない。国・県の資料と、当事者団体の報告書だけ。
- 本文はツールで取得した要約で読んでおり、一字一句は確かめられていない。図の数字は読み取りが崩れていることがあり、その場合は明記した。

## 1. 「毎日」：毎日世話をしている人は半分に届かない（事実）

| 出典 | 分かったこと（要約） |

**まとめ（事実）**：介護では、毎日世話をしている人は県の調査で4割台、同居の介護者でも「必要なときに手をかす程度」が最多。離れて暮らす家族の介護もある。育児で毎日の世話をしている人の割合は今日は調べていない（未確認。乳幼児の育児はほぼ毎日と思われるが推測）。

## 2. 「がんばっている」：頑張りを評価する言い方は避けるよう勧める公的資料がある（事実）

| 出典 | 分かったこと（要約） |
| --- | --- |
| 栃木県「ケアラー支援の手引き」（2025年3月）第3章 p.18〜19 | 見出しは「行動に対して価値付けしない」。支援者が、良いケアや頑張っているケアを「すごい」「えらい」とほめると、ケアラーがもっと評価されたくなってケアにのめり込むおそれがある、と注意している。ケアラー全般（介護者教室やケアラーズカフェを想定）についての記述。愚痴や弱音が出たときは、ひとりで大変だったことをいたわる言葉をかけるのが基本、としている |
| 同 手引き | ケアは日常の当たり前や家族の義務として行われるので、本人が自分の大変さに気づきにくく、「大丈夫」と答えがち、と書く。愚痴や弱音は悪いことではないと伝えることが大事、としている。子どもに「あなたはヤングケアラーですね」と名札を付けるような言い方は避ける、とも書く |
| 認知症の人と家族の会「認知症の介護家族が求める家族支援のあり方」（2012年3月） | 自由記述に、良くならない病気なのに周りから「もっと頑張れ」と言われてつらかった、頑張っているのに怠けていると見られて苦しい、という声がある（件数の記載なし）。気が楽になったのは、大変さを分かってもらえたとき、休むよう気づかわれたとき |

**まとめ（事実）**：「がんばって」（励まし）がつらいことは 10-17 の調査どおりで、49行で対応済み。今日新しく分かったのは、**「がんばっているね」と頑張りをほめる言い方も、ケアにのめり込ませるおそれがあるとして避けるよう勧める県の手引きがある**こと。勧められているのは、頑張りをほめるのではなく大変さをいたわること。

## 3. 「世話をしている人」という言い方と、本人の自覚（事実）

| 出典 | 分かったこと（要約） |
| --- | --- |
| 山梨県「ケアラー実態調査」結果概要（2025年3月） | **バックログの「56.6%」の読み方の注意**：56.6% は、県内の支援機関（145件）が「ケアラー支援が進まない理由」として「ケアラーである自認がない」を挙げた割合。**ケアラー本人に聞いた数字ではない**。県民調査には、自分をケアラーだと思うかを聞く設問は見当たらなかった |
| 三菱UFJリサーチ＆コンサルティング（2021年3月） | 「世話をしている家族がいる」と答えた中学2年生は 5.7% だが、自分がヤングケアラーに「あてはまる」と答えたのは 1.8%。行為（世話）を聞けば答える人の中に、呼び名（ケアラー）は自分のことと思わない人が多いことを示す（子どもの調査） |
| 栃木県 手引き（上と同じ） | 本人が自分の大変さに気づきにくい理由として、ケアが当たり前・義務になっていることを挙げる |

**まとめ（事実）**：大人の介護者が自分を「ケアラー」と思っているかを本人に聞いた数字は、今日読んだ範囲では見つからなかった（未確認）。ただ、支援機関の見方（山梨）と子どもの調査（全国）はどちらも、「世話をしている」という行為で書くほうが、呼び名で書くより本人に当てはまりやすいことを示している。今の39行は「世話」という行為で書いており、この点はすでに合っている。

### 焚き火に当てはめると（推測）

- 39行の「毎日」は、介護では半数以上の人に当てはまらない。ボットが「毎日大変だね」と決めつけると、週に何回か、離れて世話をしている人が「自分はそこまでじゃない」と感じ、吐き出しにくくなるおそれがある（推測。本番の返事は会社から見えない）。
- 「がんばっている人」は、AI に「いつもがんばってるね」「えらいね」とほめさせる下地になりうる。49行の「もう十分やっている人として、ねぎらう」とは近いが、栃木県の手引きは頑張りをほめるより大変さをいたわるほうを勧めている（推測）。
- 言い直しのたたき台（企画部・安全審査部の検討用。推測）：`相手は、子どもや親・家族の世話をしている人です。`（「毎日がんばっている」を外すだけ。いちばん小さい変更）。「疲れている人です」のように気持ちを決めつける言い方にすると、元気な日の愚痴に合わなくなるので勧めない。40行の「育児と介護が重なっている人や…」は「世話」でつながったまま読める。
- 「世話」という語は残すのがよい（行為で書くほうが当てはまりやすい）。「ケアラー」「介護者」という呼び名には変えない。

## 会社への示唆（3つ以内）

1. **(c) は「急がない」から「根拠がある」に格上げしてよい。** 39行の「毎日」は、介護で毎日世話をしている人が4割台（山梨県 2025）、同居でも「必要なときに手をかす程度」が最多（国民生活基礎調査 2022）なので、多くの人に当てはまらない。「がんばっている」は、頑張りをほめずに大変さをいたわるよう勧める県の手引き（栃木県 2025）と向きがずれる。たたき台は「毎日がんばっている」を外して `相手は、子どもや親・家族の世話をしている人です。` にする最小の言い直し（推測を含む）。
2. **「世話」という語は残し、「ケアラー」「介護者」には変えない。** 行為で書くほうが本人に当てはまりやすい（ヤングケアラー調査で、世話をしている 5.7% に対し、自分があてはまると答えたのは 1.8%）。あわせて、**バックログの「自分をケアラーだと思っていない人が多い（山梨県 2025、56.6%）」は、支援機関の回答であり本人の回答ではない**ので、根拠に書くときは「支援機関の56.6%が、本人に自認がないことを支援が進まない理由に挙げた」と直してほしい。
3. **言い直すときは49行（「もう十分やっている人として、ねぎらう」）と同じ日に触らない。** 39行だけを変え、返事が変わったときの原因を分ける。49行の「ねぎらう」が「えらいね」とほめる方向に読まれないかは、(c) を出したあとに必要が見えたら別の日に検討する（推測）。
