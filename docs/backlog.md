#### なぜこれを選んだか

- **安全性の候補で、今日作れて、出典で裏付けがあるもの**：「死んでしまいたい」「死にたくなる」「消えてしまいたい」「いなくなってしまいたい」は、ゲートキーパー資料などにそのまま出てくる言い方なのに、今の部分一致では拾えない（調査 2）。拾えないと、(a) 燃やした後に応援リンクが出る（今は `SUPPORT_URL` 未設定なので実害は出ていない）、(b) AI が答えられなかったときのおわびに 110番・119番の一文が付かない（10-12 から本番で効いている経路）。
- **スタンプのひとこと（体験の改善）は今日も選ばない**：v3 の振り分けの順番が今日も未確認（調査 4、社長の前提）。メッセージスタンプの文字の扱いも安全審査部で未判断。
- **小さく、元に戻しやすい**：処理の流れは変えず、一覧に言葉を足すだけ。

#### 足す言葉を選んだ基準

1. **出典にある言い方そのもの**、または**その活用形・ひらがな形**（今の一覧が「死にたい／しにたい」のように漢字とひらがなを両方持つ形に合わせる）。
2. 調査で「誤検知が少ない」とされ、企画部が普通の愚痴の言い方と照らしても大きな誤検知が見つからないもの。
3. **入れないもの**：出典がなく推測だけの候補（`死ぬしかない`、`死ねたら`、`死なせて`、`死んでくれ` など）、くだけた言い方で出典にない形（`死んじゃいたい`、`消えちゃいたい`、`叩いちゃい` など）、誤検知が多い候補（調査 3-2・3-3）。これらは下の候補欄に残し、安全審査部の判断を待つ。
4. **削らない**：今の一覧の誤検知（「しのう」→「わたしのうち」、「手が出」→「手が出ない」）は安全側に倒れているので今日は削らない。削ると安全性が下がる。

企画部が調査の案から外した・形を変えたもの（理由）：

- `消えたく` → **`消えたくな`／`消えたくて` に絞った**：`消えたく` だと「痛みが消えたくらい」（消えた＋くらい）に当たる。「消えたくなる」「消えたくない」「消えたくて」は拾える。ひらがなも同じ。
- `目が覚めなければ` → **今日は入れない**：育児では「夜中に子どもの目が覚めなければいいのに」という普通の願いに当たりうる（推測）。候補に残す。
- `首を締め`／`首をしめ` → **今日は入れない**：出典がなく、「自分で自分の首を締めてる」という慣用句（愚痴によく出ると推測）に当たる。
- `生きている意味` → **`生きている意味がない` に絞った**：「子どもが私の生きている意味」のような前向きな言い方に当たらないように。出典（名古屋市）の型どおり。
- `生きるのが嫌`、`生きていたくない`、`生きる意味がない` → 今日は入れない（出典の言い方ではない言い換え。候補に残す）。
- `一緒に死`／`一緒に逝`：出典（nippon.com）の「共に逝く」と、同資料が扱う介護の心中の言い換え。誤検知はほぼ見当たらないので入れる。安全審査部が「出典の言い方ではない」と判断したら、この2つだけ外して出してよい（下の「審査で外す場合」）。

#### 目的（お客さまにとって何が良くなるか）
