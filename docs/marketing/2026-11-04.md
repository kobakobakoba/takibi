# 広報部 投稿下書き 2026-11-04

広報部（marketer）。今日の本番の変更は、AI の呼び方（渡す引数・返事の長さの上限・既定モデル）が変わったら落ちるテストを足しただけで、利用者から見た動きは変わらない。そのため、**今日はアップデートのお知らせは書かない**。テスト、SDK や API の版、利用ポリシーの話も投稿の材料にしない（「最新のAIに対応」「安全性が保証」「ポリシー対応済み」のように読める書き方もしない）。

これまでの下書きの題材は、11-03 の冒頭にある一覧のとおり（10-04〜11-01）。11-02 は「燃やしたあとの一行」のお知らせと「なぜ『燃やす』なのか」、11-03 は「いちょうが、もう黄色かった」と「『何か手伝おうか』と言われて」。

今日の3本は、これらと重ならないようにした。
- 下書き1は「ちょっと座ったら、立ち上がれなくなった」という**体が先に止まってしまう瞬間**。10-25 の「台所で、立ったまま」（座る間もない）とは逆向きの場面、10-26 の「ぽっかり空いた時間」（時間が空いたときの気持ち）とは、時間ではなく体の重さの話として分けた。
- 下書き2は「蛇口の水が冷たくなった」という**11月上旬の手ざわりの季節**。11-01 の「お茶が冷める」（飲み物・時間の流れ）、11-03 の「いちょう」（外の景色）、10-20 の「衣替え」（作業）とは、水に手を入れる回数の多さという別の切り口にした。
- 下書き3は「『最近どう？』と聞かれて、気づいたら予定の報告をしていた」という**自分の気持ちを話すところまで行かなかった**場面。10-16 の「『大丈夫です』と答えた日」（気持ちを隠す）、11-03 の「手伝おうか」（頼み方）とは、話したのに気持ちだけ抜けていた、という点で分けた。

投稿はオーナーが選んで行ってください（会社は投稿しません）。3本とも、今日の変更に関係なく使えます。

## 書くときに守ったこと

- 消える話は「『燃やす』で、焚き火のサーバーにある会話を消します」に限る。「完全に」「絶対」「どこにも残らない」は使わない。下書き3には LINE のトーク画面の履歴がスマホに残ることも書く。
- AIの話は「AIが短く受け止めます」の範囲にする。心の状態を見分ける・判定するとは書かない。提供元の会社名・モデル名は書かない。
- 「いつでも」「24時間」「すぐ返事」は使わない。夜中の利用を呼びかけない。投稿時間帯も夜にしない。
- 相談窓口と比べない。窓口の名前・番号・URLは書かない。
- 気持ちへの効果を言い切らない（「楽になる」「スッキリする」「軽くなる」「疲れが取れる」「安心できます」は使わない）。指図・助言をしない（「休みましょう」「手を温めて」「気持ちも話してみて」「頼っていいんだよ」は書かない）。
- 子ども・親・家族を悪く言わない。下書き3の「最近どう？」と聞いてくれた人は、気にかけてくれた相手として書き、聞き方を責めない。誰に聞かれたかも書かない。性別や続柄で役割を決めつけない。
- 数字・統計・利用者の声は使わない。応援（投げ銭）や料金の話はしない。他社やほかのサービスの名前は出さない。
- `[友だち追加リンク]` はオーナーが差し込む部分。

## オーナーへのメモ

- **今日の変更について**：テストを足しただけで、利用者から見た動きは変わりません。お知らせにはしていません。「最新のAIに対応しました」「安全性を確認済み」「ポリシーに対応済み」のような一文は足さないでください。
- **下書き1**：「さぼっているわけじゃない」は本人の心の中の言葉として書いています。「座っていいんですよ」「休むのも大事」のような助言の一文、「疲れが取れる」「ほっとできる」のような効果の一文は足さないでください。
- **下書き2**：「蛇口の水が冷たくなった」は11月上旬〜中旬に合う言い方です。暖かい地域ではまだ実感がない時期なので、使う時期は様子を見てください。「ハンドクリームを」「お湯を使って」のような助言は足さないでください。画像を添える場合は、人や家、場所が特定できない、蛇口や水だけの写真にしてください。
- **下書き3**：聞いてくれた人は、気にかけてくれた相手として書いています。「友だちに」「母に」「夫に」など相手を足したり、「分かってくれない」「聞くだけで」のように相手を責める形には変えないでください。「気持ちも話してみましょう」「人に話すより焚き火に」のような助言・比べる一文も足さないでください。「ひとりじゃない」「さびしさが和らぐ」も足さないでください。
- **11-03・10-16 との間隔**：下書き3は、11-03 の「『何か手伝おうか』と言われて」、10-16 の「『大丈夫です』と答えた日」と同じく人とのやりとりの場面なので、続けて投稿する場合は間を空けてください。
