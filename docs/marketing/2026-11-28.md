# 広報部 投稿下書き 2026-11-28

広報部（marketer）。**未投稿の下書きです。** 投稿はオーナーが選んで行ってください（会社は投稿しません）。

今日はコード変更がないので、**アップデートのお知らせは書かない**。新しい機能の宣伝もしない。安全のための機能（危ない言葉の見張りや目印）は、あること・中身・「見守っています」のような一文も含めて、どの下書きにも入れていない。

社長からの注意（11-28）と、11-17〜11-27 の注意を続けて、次のことを守った。
- 特定の自治体・窓口の名前は載せない。窓口の番号・受付時間、統計・調査の数字、年末年始の話題も使わない。
- 「すべて拾う」「必ず守る」「誰にも見られません」「どこにも残りません」「完全に消えます」「ブロックすれば消えます」「完全無料」「費用ゼロ」のような言い切りは使わない。消えると言うのは「焚き火のサーバーにある会話」だけ。消し方として案内するのは「燃やす」だけ。
- 効き目や理解を約束しない（「楽になる」「軽くなる」「スッキリ」「分かってくれる」「ストレスが消える」は使わない）。指図・助言・説教をしない。友だち追加を強く呼びかけない。
- 「えらい」「すごい」「がんばっている」でほめない・強めない。「ママ」だけに向けない。性別・続柄・世話の相手を書かない。親・子ども・家族を悪く書かない。
- 焚き火を窓口の代わりのように書かない。「いつでも」「24時間」「すぐ返事」は使わない。夜中の利用を呼びかけない。投稿時間帯も夜にしない。

これまでの題材との分け方（`docs/marketing/` の見出しを 10-04〜11-27 まで一覧し、本文の「洗い物」「頭の中で」も検索して確かめた）。
- 下書き1は「取りこんだ洗濯物が、山のまま」という、**手が回らなかったことを、今日はそのままにしておくと自分で決めた**場面。家事が残ったままの状態を題にした下書きはこれまでにない。洗い物は 11-04・11-09 で場面に使っているので避けた。近いのは 11-11 下書き1「今日の分だけ」、11-25 下書き1「手袋が、片方ない」だが、今日は**力が抜ける一瞬ではなく、残ったものを前に「今日はここまで」と区切る**ところに絞った。「たたまなくていい」「手を抜いていい」とは読み手に言わない（許可・助言にしないため）。
- 下書き2は「言えなかったひとことが、頭の中で何度もくり返される」という、**その場では飲みこんだ言葉が、あとから頭の中で再生される**状態の紹介文。近いのは 10-08 下書き3（一日のことが頭の中で鳴っている夜）、10-13 下書き2「電話を切ったあと」、11-22 下書き1「言いかけて、やめた」だが、今日は**飲みこんだあと、その言葉が手元に残り続けること**に絞り、昼の場面にした。誰に言えなかったのか、どんな言葉だったのかは書かない（相手を悪く読ませないため）。「言えばよかった」と自分を責める話にもしない（10-18・10-20 と重ねないため）。

## 書くときに守ったこと

- 消える話は「『燃やす』で、焚き火のサーバーにある会話を消します」に限る。下書き2には LINE のトーク画面の履歴がスマホに残ることも書く。
- AIの話は「AIが短く受け止めます」「説教しないように作っています」の範囲。返事の速さ・中身は約束しない。提供元の会社名・モデル名は書かない。
- 体・病気・介助の中身は書かない。利用者の声は使わない。応援（投げ銭）や料金の話はしない。他社やほかのサービスの名前を出さない。
- `[友だち追加リンク]` はオーナーが差し込む部分。

## オーナーへのメモ

- **未投稿です。** 2本とも下書きのみで、会社からは投稿していません。
- **安全の機能の話は足さないでください（2本とも）**：「見守っています」「危ないときは知らせます」「安心の仕組み」のような一文や、自治体・窓口の名前は入れないでください。窓口を載せる場合は広報部の下書きに混ぜず、安全審査部と相談してください。
- **言い方を強めないでください（2本とも）**：「誰にも見られません」「どこにも残りません」「完全に消えます」「必ず」「すべて」には変えないでください。「完全無料」「費用ゼロ」も足さないでください。消し方は「燃やす」だけを案内してください。
- **下書き1**：「たたまなくていい」「家事は手を抜いていい」「完璧じゃなくていい」のような読み手への許可・助言の一文や、「焚き火で一日をリセット」のような効き目の一文は足さないでください。「山のままにしておくことにした」は、本人が自分で区切った場面として書いています。誰がたたむべきか（家族の誰かがやらない等）を書き足すと相手を悪く読ませるので足さないでください。画像を添える場合は、人の顔や姿・家の中が写らない、焚き火や景色だけの写真にしてください（実際の洗濯物の写真は、衣類から家族構成が分かるので避けてください）。
