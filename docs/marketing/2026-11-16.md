# 広報部 投稿下書き 2026-11-16

広報部（marketer）。**未投稿の下書きです。** 投稿はオーナーが選んで行ってください（会社は投稿しません）。

今日の変更（返事を待つ間のローディング表示）は**初期状態でオフで、利用者には見えない**。社長の申し送りと調査部 11-16 の示唆3を受けて、**アップデートのお知らせは書かず、投稿の材料にもしない**。「返事を待つ間は表示が出ます」「すぐ返事が来ます」「待たせません」「入力中が分かります」のように読める書き方もしない。返事を待つ・既読・返事が来ない、という場面そのものも今日は題材にしない（変更と結びつけて読まれないように）。

ほかに守ったこと。
- 窓口の名前・番号・URLは載せない。数字・統計は使わない。
- 「いつでも」「24時間」「すぐ返事」は使わない。夜中の利用を呼びかけない。投稿時間帯も夜にしない。
- 他社やほかのサービスの名前を出さない。比べない。

これまでの下書きの題材は、11-03 の冒頭の一覧（10-04〜11-02）と、11-03〜11-15 の各回の冒頭のとおり。今日の2本は、これらと重ならないようにした。
- 下書き1は「同じ説明を、今日三回した」という、**家族の様子を、相手を変えて何度も説明した日**の場面。10-10「同じ話でも」（焚き火に同じ話を置いてよい、という話）とは、焚き火の外で、自分が説明役を続けた一日の話として分けた。10-13「電話を切ったあと」（一本の電話のあと）、11-10「同じ画面に、並んでいた」（連絡が重なる）とは、説明を「くり返す」ことに絞って分けた。「説明」をくり返す下書きはこれまでにない。
- 下書き2は「一日じゅう、誰かのことを書いている」という、**連絡帳や申し込みの用紙、家族のことのメモなど、書く欄はたくさんあるのに、自分の言葉を書く欄はない**ことに気づく場面の紹介文。10-27「テーブルの上のプリント」（届いた紙が積まれていく話）とは、自分が書く側に回っている話として分けた。11-15「自分の誕生日を、夕方に思い出した」（自分の日が後回し）とは、「書く」ことに絞り、焚き火を「自分の言葉を書いていい欄」として紹介する点で分けた。

## 書くときに守ったこと

- 消える話は「『燃やす』で、焚き火のサーバーにある会話を消します」に限る。「完全に」「絶対」「どこにも残らない」は使わない。下書き2には LINE のトーク画面の履歴がスマホに残ることも書く。
- AIの話は「AIが短く受け止めます」の範囲にする。相談に乗る・心の状態を見分けるとは書かない。返事の速さには触れない。提供元の会社名・モデル名は書かない。
- 気持ちへの効果を言い切らない（「楽になる」「スッキリする」「軽くなる」「安心できます」は使わない）。指図・助言をしない（「ひとりで抱えないで」「自分を大切に」は書かない）。ほめる・評価する調子にもしない。
- 子ども・親・家族、説明した相手（先生・親戚・職場の人など）を悪く言わない。説明した相手は書かず、「相手を変えて」にとどめる。家族の様子の中身（病気・障害・介助・発達など）は書かない。
- 利用者の声は使わない。応援（投げ銭）や料金の話はしない。
- `[友だち追加リンク]` はオーナーが差し込む部分。
