# 広報部 投稿下書き 2026-11-10

広報部（marketer）。**未投稿の下書きです。** 投稿はオーナーが選んで行ってください（会社は投稿しません）。

今日の本番の変更（AI の返事の目印の照合を、文字のそろえ越しにも行うようにしたもの）は仕組みの内側の話なので、**アップデートのお知らせは書かず、投稿の材料にもしない**。「危ない会話を検知」「全角でも検知」「窓口に必ずつなぐ」のように読める書き方はしない。

調査部 11-10（男性の育児・介護当事者）を受けて、次のことを守った。
- 父親・息子・夫として世話をしている人にも「自分のことだ」と思ってもらえる書き方にする。ただし性別で決めつけない。「男は弱音を吐かない」「男性は相談が苦手」「男性にこそ焚き火」とは書かない（数字で確かめられていないため）。
- 調査の数字（同居の主な介護者に占める男性の割合、0歳児の父親の産後のリスク）は**今日は載せない**。介護者の割合は出典で 36.5% と 34.8% が食い違っていて、まだ照合していないため。「産後うつ」など医療の言葉も使わない。
- 「手伝う」「イクメン」のように、世話を本来の役目でないものとして扱う言葉は使わない。
- 調査で出てきた「仕事と世話の両立」は、働いていない人を外さない書き方にする。

これまでの下書きの題材は、11-03 の冒頭の一覧（10-04〜11-02）と、11-03〜11-09 の各回の冒頭のとおり。今日の2本は、これらと重ならないようにした。
- 下書き1は「仕事の連絡と、家のことの連絡が同じ画面に並ぶ」という、**仕事と世話の連絡が同時に来て、どれから返すか手が止まる**場面。10-16「職場と家のあいだ」（どちらにも話さずにいる言葉）、10-12「昼休みの5分」（休憩の短さ）、11-07「段取りが、組み直しになった日」（予定が崩れる）とは、連絡が重なるその一瞬の話として分けた。
- 下書き2は「世話をしている人の顔は、ひとつではない」という、**父親・息子・夫として世話をしている人も含めて、どの立場の人にも開いている場所だと伝える**紹介文。10-22「世話の形は、人の数だけ」（同居・別居など世話の形）、10-16「『大丈夫です』と答えた日」（周りへの答え方）とは、世話をしている人の立場の話として分けた。数字は使わない。

## 書くときに守ったこと

- 消える話は「『燃やす』で、焚き火のサーバーにある会話を消します」に限る。「完全に」「絶対」「どこにも残らない」は使わない。下書き2には LINE のトーク画面の履歴がスマホに残ることも書く。
- AIの話は「AIが短く受け止めます」の範囲にする。心の状態を見分ける・判定するとは書かない。提供元の会社名・モデル名は書かない。
- 「いつでも」「24時間」「すぐ返事」は使わない。夜中の利用を呼びかけない。投稿時間帯も夜にしない。
- 相談窓口と比べない。今日は窓口の名前・番号・URLは載せない。
- 気持ちへの効果を言い切らない（「楽になる」「スッキリする」「軽くなる」「安心できます」は使わない）。指図・助言をしない（「ひとりで抱えないで」「頼っていいんです」は書かない）。
- 子ども・親・家族・職場の人を悪く言わない。連絡をくれる相手を負担として描かない。
- 帰省・義実家・年末年始の用事を書かない。体調や病気の話につなげない。
- 利用者の声は使わない。応援（投げ銭）や料金の話はしない。他社やほかのサービスの名前は出さない。
- `[友だち追加リンク]` はオーナーが差し込む部分。
