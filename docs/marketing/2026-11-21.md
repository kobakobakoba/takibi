# 広報部 投稿下書き 2026-11-21

広報部（marketer）。**未投稿の下書きです。** 投稿はオーナーが選んで行ってください（会社は投稿しません）。

今日はボットの動きの変更について広報部への申し送りがないので、**アップデートのお知らせは書かない**。新しい機能の宣伝もしない。モデル名・料金・統計・窓口の番号は材料にしない。

企画部・調査部の今日の注意を受けて、次のことを守った。
- 「年末年始もつながる」とは書かない（今年の発表が出ていないため）。年末年始の話題そのものを今日は使わない。
- 窓口の名前・受付時間・番号・URL・ドメインは載せない。親子のための相談LINEの受付時間、地域の介護の電話の案内は書かない（一般化もしない）。
- 11-17〜11-20 の注意も続ける：焚き火を自殺予防のサービスや窓口の代わりのように書かない。「いつでも」「24時間」「すぐ返事」は使わない。夜中の利用を呼びかけない。投稿時間帯も夜にしない。「虐待」「チェックリスト」の言葉を使わない。「えらい」「すごい」「がんばっている」「十分やっている」とほめたり評価したりしない。帰省を決めつけない。窓口と比べない。

これまでの下書きの題材は、11-03 の冒頭の一覧（10-04〜11-02）と、11-03〜11-20 の各回の冒頭のとおり。今日の2本は、これらと重ならないようにした。
- 下書き1は「カバンの中身」という、**出かける前にカバンを開けると、入っているのは家族のための物ばかりで、自分の物は財布と鍵くらいだと気づく**場面。11-19「ガラスに映った顔」（見る）、11-15「自分の誕生日を、夕方に思い出した」（自分の日）とは、物の話として分けた。「カバン」「持ち物」を使った下書きはこれまでにない。入っている物は「替えの服」「ハンカチ」「予定のメモ」など、病気・薬・介助の道具にならない物にした。家族の物を「荷物」「重い」とは書かない。
- 下書き2は「友だちへの返事が、まだ書けていない」という、**友だちから届いたメッセージに、気にかけているのに返事が書けないまま数日たっている**場面の紹介文。10-15 下書き1「メモに打っては消す」（自分の吐き出したいことば）、11-04「『最近どう？』と聞かれて」（その場の答え）とは、届いたメッセージへの返事が「書けないまま」であることに絞って分けた。「友だちへの返事」を題にした下書きはこれまでにない。友だちを悪く書かない。返事をしない本人を「失礼」「だめ」とも書かない。焚き火を友だちの代わりとしても書かない。

## 書くときに守ったこと

- 消える話は「『燃やす』で、焚き火のサーバーにある会話を消します」に限る。「完全に」「絶対」「どこにも残らない」は使わない。下書き2には LINE のトーク画面の履歴がスマホに残ることも書く。
- AIの話は「AIが短く受け止めます」の範囲にする。相談に乗る・答えを出す・心の状態を見分ける・ねぎらう、とは書かない。返事の速さには触れない。提供元の会社名・モデル名は書かない。
- 気持ちへの効果を言い切らない（「楽になる」「スッキリする」「軽くなる」「安心できます」は使わない）。指図・助言をしない（「ひとりで抱えないで」「無理しないで」「自分を大切に」「早く返事しなくていい」は書かない）。
- 子ども・親・家族、友だちを悪く言わない。
- 体・病気・介助の中身は書かない。
- 数字・統計・利用者の声は使わない。応援（投げ銭）や料金の話はしない。他社やほかのサービスの名前を出さない。
- `[友だち追加リンク]` はオーナーが差し込む部分。
