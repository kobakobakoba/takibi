# 広報部 投稿下書き 2026-11-05

広報部（marketer）。今日の本番の変更は、「使い方」（`HELP_TEXT`）の最初の段落に、次の1行を足したもの。

> 育児や介護のやり方のアドバイスは、聞かれたときだけにしています。

下書き1（お知らせ）は、この変更が本番に出たのをオーナーが確かめてから使ってください。出ていない場合は使わないでください。下書き2・3は、変更が出たかどうかに関係なく使えます。

調査部 11-05（愚痴・吐き出し向けのサービスは何をしているか）と安全審査部の申し送りを受けて、次のことを守った。
- 「アドバイスしません」「アドバイスは一切なし」と**約束する書き方にしない**。AI は指示どおりにならないこともあるため、言い方は「使い方」の文どおり「聞かれたときだけにしています」（していることの説明）にとどめる。下書き3には、AI の返事なのでずれることがあると書く。
- 「唯一」「日本初」「他より安全」「ほかのアプリとちがって」と書かない。他のサービスと比べない。他社やほかのサービスの名前は出さない。
- 「何でも答えます」「相談に乗ります」「聞けば教えてくれます」と書かない（窓口の代わりや、医療・法律の判断をする場所と読まれないため）。「知りたいときは聞いてください」のような呼びかけも書かない。
- 調査の中身（ほかのアプリの記事、自治体の AI 相談、相談メモ）は投稿の材料にしない。

これまでの下書きの題材は、11-03 の冒頭にある一覧のとおり（10-04〜11-01）。11-02 は「燃やしたあとの一行」のお知らせと「なぜ『燃やす』なのか」、11-03 は「いちょうが、もう黄色かった」と「『何か手伝おうか』と言われて」、11-04 は「ちょっと座ったら」「水が冷たくなった」「『最近どう？』と聞かれて」。

今日の3本は、これらと重ならないようにした。
- 下書き1は**「使い方」に足した1行**のお知らせ。アドバイスの扱いを話題にするのは初めて。10-31（あいさつ）、11-02（燃やしたあと）のお知らせとは、変えた場所がちがう。
- 下書き2は「やり方は分かっている。でも今日はできなかった」という**頭では分かっているのに、体と時間が追いつかなかった**場面。人とのやりとりの場面（11-03・11-04 下書き3）を続けないよう、ほかの人が出てこない、本人の中だけの話にした。11-04 下書き1「ちょっと座ったら」（体が止まる瞬間）とは、「知っている／できる」のずれの話として分けた。
- 下書き3は note 向けに、**なぜ「聞かれたときだけ」にしているのか**を書く。これまでの「焚き火が、しないこと」（10-30）は保存や広告の話で、返事の中身の方針には触れていない。

投稿はオーナーが選んで行ってください（会社は投稿しません）。

## 書くときに守ったこと

- 消える話は「『燃やす』で、焚き火のサーバーにある会話を消します」に限る。「完全に」「絶対」「どこにも残らない」は使わない。下書き3には LINE のトーク画面の履歴がスマホに残ることも書く。
- AIの話は「AIが短く受け止めます」の範囲にする。心の状態を見分ける・判定するとは書かない。提供元の会社名・モデル名は書かない。11-03・11-04 で使った「答えを出したりもしません」は、今日は約束に読まれやすいので使わない。
- 「いつでも」「24時間」「すぐ返事」は使わない。夜中の利用を呼びかけない。投稿時間帯も夜にしない。
- 相談窓口と比べない。窓口の名前・番号・URLは書かない。
- 気持ちへの効果を言い切らない（「楽になる」「スッキリする」「軽くなる」「安心できます」は使わない）。指図・助言をしない（「できない日があってもいい」「自分を許して」「休みましょう」は書かない）。
- アドバイスをくれる人を悪く言わない。「アドバイスされて疲れる」「解決策を押しつけられる」のように、まわりの人（家族を含む）の言い方を責める書き方をしない。
- 子ども・親・家族を悪く言わない。性別や続柄で役割を決めつけない。
- 数字・統計・利用者の声は使わない。応援（投げ銭）や料金の話はしない。
- `[友だち追加リンク]` はオーナーが差し込む部分。

## オーナーへのメモ

- **下書き1の使いどころ**：今日の変更が本番に出たのを確かめてから使ってください。「アドバイスはしません」「アドバイス一切なし」「アドバイスなしで聞きます」のような、約束や言い切りの形には変えないでください（AIは指示どおりにならないこともあるため）。「ほかのアプリとちがって」「最初から設定いらず」「唯一」「日本初」のような比べる一文、「聞けば何でも答えます」「相談に乗ります」も足さないでください。
- **下書き2**：「分かっているぶん、よけいに頭に残る」は本人の心の中の言葉として書いています。「できない日があってもいい」「自分を責めないで」のような助言、「気持ちが軽くなる」のような効果の一文は足さないでください。誰かに何か言われた場面（「〜すればいいのにと言われた」など）にも変えないでください（まわりの人を責める読み方になるため）。
- **下書き3**：「やり方なら、もう調べて、考えて、試しています」は「多くは」と幅を持たせています。「みんなそうです」と言い切る形にはしないでください。「AIの返事なので、ずれることもあります」の一文は、約束に読まれないための大事な部分なので、字数の都合でも消さないでください。短くしたい場合は、2段落目（理由の段落）を削ってください。調査で見た、ほかのアプリやまとめ記事の話は足さないでください。
- **下書き1と3の間隔**：同じ一行を紹介しているので、続けて投稿する場合は、どちらか1本にするか、数日空けてください。
