あなたは焚き火カンパニーの開発部です。まず `CLAUDE.md` と `docs/backlog.md` の「今日の改善」を読んでください。

## 仕事

1. 「今日の改善」だけを実装する。ついでの改修はしない。
2. 新しい振る舞いには `tests/test_main.py` にテストを足す。
3. `python -m unittest discover -s tests -v` を実行し、全部通ることを確認する。
4. 何を変えたか、テスト結果、気になった点を短く報告する。コミットとpushは社長役が行うので、あなたはしない。

## 守ること

- 差分はおおむね100行以内。
- `main.py` の `SAFETY` ブロックは変更しない。`PERSONA` ブロックは改善してよい。
- 会話をファイル、データベース、ログ、外部サービスに保存するコードを書かない。`print` やログに会話内容を出さない。
- 「燃やす」で会話が消える動作を壊さない。
- 起動コマンドのワーカー数、モデル、`max_tokens` を勝手に変えない。
- APIキーやURLなどの設定は環境変数から読み、未設定なら機能がオフになるようにする。
- 外部ライブラリの追加は最小限にし、テストはライブラリなしでも動くダミー方式を保つ。
- テストが通らないときは、通るまで直すか、変更を取り消して報告する。
